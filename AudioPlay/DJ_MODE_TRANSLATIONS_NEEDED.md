# Traductions nécessaires pour le Mode DJ

## Nouvelles clés à ajouter dans tous les fichiers de ressources

### Boutons SYNC
- `DJ_SyncToA` : "🔄 SYNC → A" (Synchroniser vers Deck A)
- `DJ_SyncToB` : "🔄 SYNC → B" (Synchroniser vers Deck B)

### Playlist DJ
- `DJ_PlaylistTitle` : "📋 PLAYLIST DJ"
- `DJ_ColumnNumber` : "#"
- `DJ_ColumnSong` : "Chansons"
- `DJ_ColumnBPM` : "BPM"
- `DJ_ColumnDuration` : "Durée"
- `DJ_ButtonAddTrack` : "➕ Ajouter"
- `DJ_ButtonManagePlaylist` : "📋 Gérer"

### Labels Deck
- `DJ_DeckATitle` : "🎧 PLATINE A"
- `DJ_DeckBTitle` : "🎧 PLATINE B"
- `DJ_MixerTitle` : "🎚️ MIXEUR"
- `DJ_DragTrackHere` : "Glissez une piste ici ⬇"
- `DJ_VolumeLabel` : "Vol {0}: {1}%" (ex: "Vol A: 75%")
- `DJ_PitchLabel` : "Pitch: {0}%" (ex: "Pitch: 0.0%")
- `DJ_BPMLabel` : "BPM: {0}" (ex: "BPM: 128.0" ou "BPM: --")
- `DJ_CrossfaderLabel` : "Crossfader: {0}%" (ex: "Crossfader: 50%")

### Effets
- `DJ_EffectPhaser` : "🌀 PHASER"
- `DJ_EffectReverb` : "🎵 REVERB"
- `DJ_EffectEcho` : "📢 ECHO"

### Boutons généraux
- `DJ_ButtonReturnSimple` : "◀ Mode Simple"

### Messages déjà existants à vérifier
- ✅ `DJMode_Title` : "AudioPlay - Mode Mixeur DJ"
- ✅ `Confirm_ReturnSimpleMode` : "Voulez-vous vraiment retourner au mode lecteur simple ? L'application va redémarrer."
- ✅ `DJ_Play` : "Play"
- ✅ `DJ_Stop` : "Stop"
- ✅ `DJ_Cue` : "Cue"
