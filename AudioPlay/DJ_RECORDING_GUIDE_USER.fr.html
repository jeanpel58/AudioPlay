🎙️ Guide d'enregistrement - Mode DJ

Enregistrez vos sessions de mixage en toute simplicité

📋 Vue d'ensemble

La fonction d'enregistrement DJ vous permet de capturer vos sessions de mixage en temps réel, dans plusieurs formats audio de haute qualité. Que vous créiez un podcast, un set DJ ou simplement que vous souhaitiez conserver vos meilleurs mixes, cette fonctionnalité est conçue pour vous.

🚀 Démarrage rapide

1. Préparation

  • Chargez au moins une piste sur l'un des decks (A ou B)
  • Sélectionnez le format d'enregistrement souhaité dans la liste déroulante
  • Le format par défaut est MP3 320 kbps

2. Démarrage de l'enregistrement

Étape par étape :

  1. Cliquez sur le bouton ⬤ REC
  2. Sélectionnez le répertoire de destination pour votre mix
  3. Un message de confirmation s'affiche avec le nom du fichier
  4. Le bouton devient ⬛ STOP
  5. La durée d'enregistrement s'affiche en temps réel
💡 Astuce : Le répertoire de destination est mémorisé entre les sessions. Vous n'aurez à le sélectionner qu'une seule fois !

3. Enregistrement en cours

Pendant l'enregistrement :

  • Mixez normalement avec vos deux decks
  • Utilisez le crossfader, les effets, le pitch
  • La durée s'affiche au format HH:MM:SS
  • Tout le son sortant de votre système est capturé
⚠️ Attention : L'enregistrement capture TOUTE la sortie audio de votre système. Évitez les notifications système ou autres sons parasites pendant l'enregistrement.

4. Arrêt de l'enregistrement

  • Cliquez sur le bouton ⬛ STOP
  • Un message de confirmation affiche la durée totale et l'emplacement du fichier
  • Vous pouvez ouvrir directement le dossier contenant votre mix

📁 Organisation des fichiers

Nom des fichiers :

Les enregistrements sont automatiquement nommés avec un horodatage :

DJMix_AAAA-MM-JJ_HH-MM-SS.extension

Exemple : DJMix_2026-06-02_15-30-45.mp3

🛠️ Conseils et bonnes pratiques

Qualité optimale

  • Pour l'archivage : Utilisez le format WAV
  • Pour le partage : MP3 320 kbps offre un excellent compromis
  • Pour les podcasts : MP3 192 kbps est suffisant

Espace disque

💡 Estimation de taille (pour 1 heure) :
  • WAV : ~600 MB
  • MP3 320 kbps : ~144 MB
  • MP3 192 kbps : ~86 MB
  • MP3 128 kbps : ~58 MB

Performance

  • L'enregistrement n'affecte pas les performances de lecture
  • L'encodage MP3 est optimisé pour un usage temps réel
  • Assurez-vous d'avoir suffisamment d'espace disque disponible

❓ Dépannage

L'enregistrement ne démarre pas

Solutions possibles :

  • Vérifiez qu'au moins une piste est chargée
  • Assurez-vous d'avoir les droits d'écriture dans le dossier de destination
  • Vérifiez qu'il y a suffisamment d'espace disque disponible

Pas de son enregistré

Solutions possibles :

  • Vérifiez que le volume principal n'est pas à zéro
  • Vérifiez les paramètres audio de Windows (périphérique de sortie)
  • Redémarrez AudioPlay et réessayez

Le fichier est corrompu

Solutions possibles :

  • Arrêtez correctement l'enregistrement avec le bouton STOP
  • Ne fermez pas AudioPlay pendant un enregistrement
  • Vérifiez l'intégrité de votre disque dur

🎓 Techniques avancées

Enregistrement de sets longs

Pour les sessions de plusieurs heures :

  • Privilégiez le format MP3 320 kbps pour économiser de l'espace
  • Surveillez l'espace disque disponible
  • Prévoyez des pauses pour sauvegarder et redémarrer

Post-production

Après l'enregistrement :

  • Normalisez le volume avec un logiciel audio (Audacity, etc.)
  • Ajoutez des tags ID3 pour organiser vos mixes
  • Découpez les silences au début et à la fin si nécessaire

🔮 Futures améliorations

Prochainement disponibles :
