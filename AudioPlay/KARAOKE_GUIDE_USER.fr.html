🎤 Guide d'utilisation du Karaoke CDG

📌 Qu'est-ce que le CDG ?
CDG (CD+Graphics) est un format standard de karaoke qui affiche les paroles synchronisées avec la musique. Les fichiers .cdg contiennent les graphiques et le texte qui apparaissent à l'écran pendant la chanson.

🚀 Démarrage rapide

1️⃣ Préparation des fichiers

Pour utiliser le karaoke, vous devez avoir :

  • Un fichier audio (MP3, WAV, FLAC, etc.)
  • Un fichier CDG portant le même nom que votre fichier audio
  • Les deux fichiers doivent être dans le même répertoire
📁 Exemple de structure : 
C:\Musique\Karaoke\
  ├── Ma Chanson Préférée.mp3
  └── Ma Chanson Préférée.cdg  ← Même nom que le fichier audio

2️⃣ Utilisation automatique

  1. Ajoutez votre chanson à la playlist d'AudioPlay
  2. Sélectionnez la chanson dans la liste
  3. Lancez la lecture avec le bouton ▶
  4. Si un fichier CDG est détecté, la fenêtre karaoke s'ouvre automatiquement
✅ C'est prêt !
Les paroles s'affichent automatiquement, synchronisées avec la musique. Vous pouvez déplacer et redimensionner la fenêtre karaoke selon vos besoins. Quand vous passez à une chanson sans fichier CDG, la fenêtre se ferme automatiquement.

Fenêtre karaoke

  • Redimensionnable : Ajustez la taille selon votre écran
  • Détachable : Déplacez-la sur un autre écran
  • Zoom automatique : Les graphiques s'adaptent à la taille de la fenêtre
  • Barre de statut : Affiche l'état et le nom du fichier CDG chargé

💡 Conseils d'utilisation

🎯 Pour une session karaoke réussie

  • Plein écran : Agrandissez la fenêtre karaoke pour une meilleure lisibilité
  • Second écran : Déplacez la fenêtre karaoke sur un écran externe ou projecteur
  • Playlist : Préparez votre playlist à l'avance avec toutes vos chansons karaoke
  • Volume : Ajustez le volume avec la TrackBar dans AudioPlay
  • Égaliseur : Utilisez les contrôles Basses/Aigües pour améliorer les voix

🔍 Où trouver des fichiers CDG ?

  • Sites de karaoke en ligne (légaux et payants)
  • Collections de karaoke commerciales
  • Logiciels de création de karaoke (pour créer vos propres CDG)
⚠️ Important : Respectez les droits d'auteur. N'utilisez que des fichiers CDG dont vous possédez les droits ou qui sont libres de droits.

🔧 Résolution de problèmes

❌ "Aucun fichier CDG trouvé"

Causes possibles :

  • Le fichier .cdg n'existe pas dans le même répertoire
  • Le nom du fichier .cdg ne correspond pas exactement au fichier audio
  • Extension de fichier incorrecte (doit être .cdg en minuscules)

Solution : Vérifiez que les noms de fichiers correspondent exactement (y compris majuscules/minuscules sur certains systèmes).

❌ La fenêtre karaoke ne s'affiche pas

Solution :

  1. Vérifiez que le bouton K est bien activé (coloré)
  2. Essayez de cliquer à nouveau sur le bouton K
  3. Redémarrez AudioPlay si nécessaire

❌ Les paroles ne sont pas synchronisées

Causes possibles :

  • Fichier CDG corrompu ou incompatible
  • Le fichier audio a été modifié (coupé, rallongé) après création du CDG

Solution : Utilisez un fichier CDG original non modifié, correspondant à la version exacte du fichier audio.

❌ L'affichage est déformé ou incorrect

Cause : Format CDG non standard ou fichier corrompu.

Solution : Obtenez un fichier CDG provenant d'une source fiable.

📋 Spécifications techniques

Format CDG supporté

  • Résolution : 288×192 pixels (zone d'affichage)
  • Couleurs : 16 couleurs simultanées
  • Fréquence : 300 paquets par seconde
  • Synchronisation : Automatique avec la lecture audio
  • Formats audio compatibles : MP3, WAV, FLAC, OGG, WMA, etc.

🎵 Exemples d'utilisation

Scénario 1 : Soirée karaoke entre amis

  1. Créez un dossier Karaoke avec vos chansons + CDG
  2. Ajoutez toutes les chansons à AudioPlay
  3. Activez le mode karaoke avec le bouton K
  4. Connectez votre PC à une TV ou projecteur
  5. Déplacez la fenêtre karaoke sur l'écran externe
  6. Agrandissez-la en plein écran
  7. Profitez de votre soirée karaoke !

Scénario 2 : Entraînement vocal

  1. Chargez vos exercices vocaux avec CDG
  2. Utilisez l'égaliseur pour réduire les voix originales (baisser les aigües)
  3. Augmentez le volume pour bien entendre la musique
  4. Suivez les paroles à l'écran pour pratiquer
