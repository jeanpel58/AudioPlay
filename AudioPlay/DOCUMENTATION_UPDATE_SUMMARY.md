## 🔄 Changements principaux à refléter dans TOUS les guides

### 1. Section "Créer votre propre thème"

**Ancien flux (3 étapes) :**
1. Personnaliser les couleurs
2. Choisir vos couleurs
3. Enregistrer votre thème

**Nouveau flux (5 étapes) :**
1. **Ouvrir l'éditeur de thème**
   - Peut partir de n'importe quel thème
   - Sélectionner un thème de base puis cliquer "Créer un thème de couleurs..."

2. **Personnaliser les couleurs**
   - Liste des éléments modifiables
   - Sélectionner un élément
   - Cliquer "Choisir couleur..."

3. **Prévisualiser vos changements**
   - Cliquer "Appliquer" pour voir en temps réel
   - ⚠️ Modifications temporaires jusqu'à la sauvegarde

4. **Sauvegarder votre thème**
   - Cliquer "OK"
   - Entrer un nom unique
   - 🔒 Impossible d'utiliser les noms réservés : Par défaut, Automne, Océan, Soleil, Sombre
   - Cliquer OK pour confirmer, ou laisser vide pour annuler
   - L'apparence revient à l'état d'origine

5. **Activer votre nouveau thème**
   - Sélectionner le thème dans la liste déroulante
   - Cliquer "Sauvegarder" pour appliquer définitivement

### 2. Nouvelle section "Dupliquer un thème existant"

**Contenu :**
- Sélectionner le thème à dupliquer
- Cliquer "Enregistrer le thème sous"
- Entrer un nouveau nom
- Une copie identique est créée
- Peut ensuite être modifiée avec "Créer un thème de couleurs..."

### 3. Section "Supprimer un thème" - Mise à jour

**Ancien texte :**
> ⚠️ Note : Le thème "Par défaut" ne peut pas être supprimé.

**Nouveau texte :**
> ⚠️ Note : Les thèmes préinstallés suivants ne peuvent pas être supprimés :
> - 🎨 Par défaut
> - 🍂 Automne
> - 🌊 Océan
> - ☀️ Soleil
> - 🌙 Sombre
> 
> Ces thèmes sont protégés pour garantir que vous avez toujours des options de base disponibles.

### 4. Section "Réinitialiser les couleurs" - Mise à jour

**Ancien texte :**
> À tout moment, cliquez sur "Réinitialiser" pour revenir aux couleurs par défaut d'AudioPlay.

**Nouveau texte :**
> À tout moment, cliquez sur "Couleurs par défaut" pour revenir aux couleurs par défaut d'AudioPlay.
> ⚠️ Ce bouton n'est disponible que si vous n'avez pas sélectionné un thème préinstallé protégé.
> 💡 Cette action ne supprime pas vos thèmes personnalisés, vous pourrez toujours les réutiliser plus tard.

### 5. Section "Astuces" - Mise à jour

**Anciennes astuces :**
- Tester avant d'enregistrer
- Annuler les modifications
- Partager vos thèmes
- Créer des variations

**Nouvelles astuces :**
- **Partir d'une base** : Sélectionner un thème existant avant de cliquer "Créer un thème de couleurs..."
- **Prévisualiser en direct** : Cliquer "Appliquer" dans l'éditeur pour voir instantanément
- **Annuler facilement** : Cliquer "Annuler" ou laisser le nom vide lors de la sauvegarde
- **Dupliquer pour modifier** : Utiliser "Enregistrer le thème sous" pour créer une copie modifiable
- **Partager vos créations** : Copier les fichiers `.theme` pour partager
- **Protéger vos créations** : Les thèmes utilisateur peuvent être modifiés, contrairement aux préinstallés
