# 🎨 AudioPlay Color Themes - User Guide

## 🎉 New Features!

AudioPlay now features a complete color theme management system. You can fully customize the appearance of your audio player!

## 🚀 Quick Start

### How to change themes?

1. Open **Settings** (menu or settings button)
2. Go to the **"Interface colors"** section
3. Use the **"Select a theme"** dropdown menu
4. Choose from:
   - 🎨 **Default** - Original AudioPlay theme (light blue)
   - 🌙 **Dark** - Night mode with dark gray background
   - ☀️ **Sun** - Bright and energetic yellow
   - 🌊 **Ocean** - Soothing sky blue
   - 🍂 **Autumn** - Warm golden tones

The theme applies **instantly** to the entire interface!

---

## ✨ Create your own theme

### Step 1: Customize colors

1. In **Settings** > **Interface colors**
2. Click **"Customize..."**
3. A window opens with all customizable elements:
   - Form backgrounds
   - Control backgrounds
   - Button colors
   - Playlist colors
   - And much more!

### Step 2: Choose your colors

1. Select an element from the list
2. Click **"Choose color..."**
3. Use the color picker
4. Click **"Apply"** to see the result in real-time
5. Continue until you get the desired appearance
6. Click **"OK"** when satisfied

### Step 3: Save your theme

1. Click **"Save as..."**
2. Enter a name for your theme (e.g., "My purple theme")
3. Confirm
4. Your theme is now in the list!

---

## 🗑️ Delete a theme

1. Select the theme to delete from the dropdown list
2. Click **"Delete"**
3. Confirm deletion
4. The **"Default"** theme will be automatically reactivated

⚠️ **Note**: The "Default" theme cannot be deleted.

---

## 🔄 Reset colors

At any time, click **"Reset"** to return to AudioPlay's default colors.

This does not delete your custom themes, you can still use them later.

## 💾 Share your themes

### Export a theme to share

Themes are stored as `.theme` files in:
```
%AppData%\AudioPlay\Themes\
```

To share one of your themes:
1. Open this folder (paste the path above in Windows Explorer)
2. Copy the corresponding `.theme` file (e.g., `My purple theme.theme`)
3. Send this file to another user

### Import a received theme

If you receive a `.theme` file from another user:
1. Open the `%AppData%\AudioPlay\Themes\` folder
2. Paste the received `.theme` file there
3. Restart AudioPlay or refresh the settings list
4. The new theme appears in the dropdown list

## 💡 Tips

- **Test in real-time**: Use the "Apply" button in the theme editor to see your changes immediately
- **Save regularly**: Save your changes under a new name before continuing to experiment
- **Name clearly**: Give descriptive names to your themes (e.g., "Starry Night", "Pastel Pink") to find them easily
- **Important contrast**: Make sure text remains readable on the backgrounds you choose

## 🔧 Troubleshooting

### My theme doesn't appear in the list
- Check that the `.theme` file is in `%AppData%\AudioPlay\Themes\`
- Restart AudioPlay
- The file must have the `.theme` extension (not `.theme.txt`)

### Colors are weird after modification
- Use the "Reset" button to return to the default theme
- Delete the problematic theme and recreate it

### I can't delete a theme
- The "Default" theme cannot be deleted as a safety measure
- Make sure you're not trying to modify/delete an active theme

### Text is unreadable on some backgrounds
- In **"Customize..."**, adjust text colors
- General rule: light text on dark background, dark text on light background
- Use the **"Apply"** button to check
