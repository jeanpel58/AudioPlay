### 3. Ajouter un lien dans l'aide d'AudioPlay

Dans le menu Aide ou FormDJ :

```vb
Private Sub ButtonAideEnregistrement_Click(sender As Object, e As EventArgs)
	Dim langue = LanguageManager.GetCurrentLanguage() ' "fr", "en", "es", "it", "de"
	Dim fichierAide = $"DJ_RECORDING_GUIDE_USER.{langue}.html"
	Dim cheminAide = Path.Combine(Application.StartupPath, fichierAide)

	If File.Exists(cheminAide) Then
		Process.Start(cheminAide)
	Else
		' Fallback en anglais
		Process.Start(Path.Combine(Application.StartupPath, "DJ_RECORDING_GUIDE_USER.en.html"))
	End If
End Sub
```
