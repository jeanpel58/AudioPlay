🎨 AudioPlay - Color Themes System

🎉 New Features!
AudioPlay now has a complete color theme management system. You can fully customize the appearance of your audio player!

🚀 Quick Start

How to change theme?

  1. Open Settings (menu or settings button)
  2. Go to "Interface colors" section
  3. Use the "Select a theme" dropdown menu
  4. Choose from:
    • 🎨 Default - Original AudioPlay theme (light blue)
    • 🌙 Dark - Night mode with dark gray background
    • ☀️ Sun - Bright and energetic yellow
    • 🌊 Ocean - Soothing sky blue
    • 🍂 Autumn - Warm golden tones

The theme applies instantly to the entire interface!

✨ Create Your Own Theme

Step 1: Open the Theme Editor

  1. In Settings > Interface colors
  2. Click on "Create a color theme..."
  3. 💡 Tip: You can start from any theme! First select a theme you like, then click "Create a color theme..." to customize it

Step 2: Customize Colors

  1. A window opens with all customizable elements:
    • Form backgrounds
    • Control backgrounds
    • Button colors
    • Playlist colors
    • And much more!
  2. Select an element from the list
  3. Click "Choose color..."
  4. Use the color picker to select your color

Step 3: Preview Your Changes

  1. Click "Apply" to see your changes in real-time
  2. ✨ The interface updates instantly!
  3. Continue adjusting colors until you get the desired result
  4. ⚠️ Important: These changes are temporary and won't be saved until you save the theme

Step 4: Save Your Theme

  1. When satisfied with the result, click "OK"
  2. A dialog box asks for your theme name
  3. Enter a unique name (e.g., "My Purple Theme", "Professional Theme")
  4. 🔒 Warning: You cannot use these reserved names:
    • Default
    • Autumn
    • Ocean
    • Sun
    • Dark
  5. Click OK to confirm, or leave empty to cancel
  6. ✅ Your theme is saved and now appears in the list!
  7. 📋 The appearance returns to its original state (before your changes)

Step 5: Activate Your New Theme

  1. In the "Select a theme" dropdown, choose your new theme
  2. The preview displays instantly
  3. Click "Save" to permanently apply the theme

📋 Duplicate an Existing Theme

  1. Select the theme you want to duplicate from the list
  2. Click "Save theme as"
  3. Enter a new name for the copy
  4. ✅ An identical copy is created with the new name!
  5. You can then modify it with "Create a color theme..."

🗑️ Delete a Theme

  1. Select the theme to delete from the dropdown list
  2. Click "Delete"
  3. Confirm deletion
  4. The "Default" theme will be automatically reactivated
⚠️ Note: The following preinstalled themes cannot be deleted:
  • 🎨 Default
  • 🍂 Autumn
  • 🌊 Ocean
  • ☀️ Sun
  • 🌙 Dark
These themes are protected to ensure you always have basic options available.

🔄 Reset Colors

At any time, click "Default Colors" to return to AudioPlay's default colors.

⚠️ This button is only available when you haven't selected a protected preinstalled theme.

💡 This action does not delete your custom themes; you can still reuse them later.

💾 Where Are Themes Stored?

Themes are saved in:

%AppData%\AudioPlay\Themes\

Each theme is a simple text file with the .theme extension

🔧 Tips

  • Start from a base: Select an existing theme you like before clicking "Create a color theme..." - your changes will start from that theme!
  • Live preview: Click "Apply" in the editor to see your changes instantly
  • Easy cancellation: If you don't like the result, click "Cancel" in the editor or leave the name empty when saving
  • Duplicate to modify: Use "Save theme as" to create a copy of a theme you can then customize
  • Share your creations: Copy .theme files to share with other users
  • Protect your creations: Themes you create can be modified and re-saved, unlike preinstalled themes which are protected

❓ Common Issues

Theme doesn't apply after restart

Solution: Make sure to click "Save" after selecting the theme. The "Cancel" button cancels all changes.

Buttons with images have a background color

Solution: This issue has been fixed. If you still encounter it, close and restart AudioPlay.

My custom theme disappeared

Solution: Check in %AppData%\AudioPlay\Themes\ if your .theme file still exists. If yes, the theme should appear in the list on next startup.

💡 Tip: Don't hesitate to experiment! You can always return to the default theme by clicking "Reset" or selecting "Default" from the list.
