🎤 CDG Karaoke User Guide

📌 What is CDG?
CDG (CD+Graphics) is a standard karaoke format that displays synchronized lyrics with music. .cdg files contain the graphics and text that appear on screen during the song.

🚀 Quick Start

1️⃣ File Preparation

To use karaoke, you need:

  • An audio file (MP3, WAV, FLAC, etc.)
  • A CDG file with the same name as your audio file
  • Both files must be in the same directory
📁 Example structure: 
C:\Music\Karaoke\
  ├── My Favorite Song.mp3
  └── My Favorite Song.cdg  ← Same name as audio file

2️⃣ Automatic Usage

  1. Add your song to the AudioPlay playlist
  2. Select the song from the list
  3. Start playback with the ▶ button
  4. If a CDG file is detected, the karaoke window opens automatically
✅ You're ready!
Lyrics display automatically, synchronized with the music. You can move and resize the karaoke window as needed. When you switch to a song without a CDG file, the window closes automatically.

🔧 Troubleshooting

❌ "No CDG file found"

Possible causes:

  • The .cdg file doesn't exist in the same directory
  • CDG file name doesn't exactly match audio file
  • Incorrect file extension (must be .cdg lowercase)

Solution: Verify file names match exactly (including case sensitivity on some systems).

❌ Karaoke window doesn't appear

Solution:

  1. Check that the K button is activated (colored)
  2. Try clicking the K button again
  3. Restart AudioPlay if necessary

❌ Lyrics are not synchronized

Possible causes:

  • Corrupted or incompatible CDG file
  • Audio file was modified (cut, extended) after CDG creation

Solution: Use an unmodified original CDG file matching the exact audio file version.

❌ Display is distorted or incorrect

Cause: Non-standard CDG format or corrupted file.

Solution: Obtain CDG file from a reliable source.

📋 Technical Specifications

Supported CDG Format

  • Resolution: 288×192 pixels (display area)
  • Colors: 16 simultaneous colors
  • Frequency: 300 packets per second
  • Synchronization: Automatic with audio playback
  • Compatible audio formats: MP3, WAV, FLAC, OGG, WMA, etc.
