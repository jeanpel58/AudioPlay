# 🎙️ Enregistrement DJ - Guide Rapide

## En 4 étapes simples

### 1️⃣ Préparer

```
┌─────────────────┐
│   DECK A        │
│  ♪ House.mp3    │
│  [▶] [■] [CUE]  │
└─────────────────┘

┌─────────────────┐
│   DECK B        │
│  ♪ Techno.mp3   │
│  [▶] [■] [CUE]  │
└─────────────────┘
```

✅ **Chargez au moins une piste**

---

### 2️⃣ Choisir le format

```
┌──────────────────────────┐
│ Format: [MP3 320 kbps ▼] │
└──────────────────────────┘
```

📌 **Recommandé : MP3 320 kbps**
- Excellente qualité
- Taille raisonnable (~144 MB/heure)
- Compatible partout

💡 **Autres choix :**
- **WAV** : Qualité parfaite (~600 MB/heure)
- **MP3 256** : Très bonne qualité (~115 MB/heure)
- **MP3 192** : Bonne qualité (~86 MB/heure)
- **MP3 128** : Qualité correcte (~57 MB/heure)

---

### 3️⃣ Enregistrer

```
┌────────────┐
│  ⬤ REC     │  ← Cliquez ici !
└────────────┘
```

**Première utilisation :**
- Une fenêtre s'ouvre
- Choisissez votre dossier (ex: `Documents\AudioPlay\Recordings`)
- Le dossier sera mémorisé

**Pendant l'enregistrement :**

```
┌────────────┐
│  ⬛ STOP    │  ← Bouton gris
│  00:32:15   │  ← Durée en temps réel
└────────────┘
```

✅ **Mixez normalement** :
- Utilisez le crossfader
- Changez le volume
- Activez les effets
- Synchronisez les beats

🎵 **Tout est capturé !**

---

### 4️⃣ Arrêter & Sauvegarder

```
┌────────────┐
│  ⬛ STOP    │  ← Cliquez pour arrêter
└────────────┘
```

**Message de fin :**

```
╔════════════════════════════════════╗
║  Enregistrement terminé !          ║
║                                    ║
║  Durée: 01:23:45                   ║
║  Fichier: DJ_Mix_20260602_143000.mp3 ║
║                                    ║
║  Voulez-vous ouvrir le dossier ?   ║
║                                    ║
║       [ Oui ]      [ Non ]         ║
╚════════════════════════════════════╝
```

✅ **Cliquez "Oui"** → Le dossier s'ouvre dans l'explorateur

## 💡 Astuces Express

### ✨ Pour un mix parfait

1. **Testez vos niveaux AVANT** d'enregistrer
   - Les VU-mètres ne doivent pas être en rouge

2. **Silence les autres apps** pendant l'enregistrement
   - L'enregistrement capture TOUT le son Windows

3. **Préparez votre setlist** dans la playlist DJ
   - Gagnez du temps pendant le mix

### 🎚️ Raccourcis utiles

- **Shift + ⬤ REC** = Changer le dossier d'enregistrement
- **⬛ STOP** = Arrêter et sauvegarder proprement

### 📂 Où sont mes fichiers ?

**Dossier par défaut :**
```
C:\Users\VotreNom\Documents\AudioPlay\Recordings\
```

**Nommage automatique :**
```
DJ_Mix_20260602_143000.mp3
		↑       ↑
	 Date     Heure
```

## ❓ Problèmes courants

### Le bouton REC ne fait rien
➡️ **Chargez une piste** sur un deck avant

### L'enregistrement ne démarre pas
➡️ Vérifiez l'**espace disque** (besoin de ~144 MB/heure pour MP3 320)

### Le fichier est vide
➡️ **Arrêtez proprement** avec le bouton ⬛ STOP (ne fermez pas brutalement)

### J'entends d'autres sons dans mon mix
➡️ **Mettez en sourdine** les autres applications Windows pendant l'enregistrement

## 🎓 Comparaison formats

| Format | Qualité | Taille (1h) | Quand l'utiliser ? |
|--------|---------|-------------|-------------------|
| **WAV** | ⭐⭐⭐⭐⭐ | 600 MB | Archivage, mastering |
| **MP3 320** | ⭐⭐⭐⭐☆ | 144 MB | **Usage général (recommandé)** |
| **MP3 256** | ⭐⭐⭐⭐☆ | 115 MB | Qualité élevée, taille réduite |
| **MP3 192** | ⭐⭐⭐☆☆ | 86 MB | Partage web |
| **MP3 128** | ⭐⭐☆☆☆ | 57 MB | Tests, brouillons |

💎 **Conseil pro :** MP3 320 kbps est le meilleur compromis qualité/taille pour 99% des usages

## 🚀 Workflow professionnel

### Avant la session

```
1. [ ] Ouvrir AudioPlay en Mode DJ
2. [ ] Créer/charger une playlist
3. [ ] Vérifier les niveaux audio
4. [ ] Choisir le format d'enregistrement
```

### Pendant la session

```
1. Cliquer sur ⬤ REC
2. Mixer normalement (le timer compte)
3. Garder un œil sur les VU-mètres
```

### Après la session

```
1. Cliquer sur ⬛ STOP
2. Ouvrir le dossier
3. Renommer le fichier (optionnel)
   DJ_Mix_20260602_143000_Summer2026.mp3
4. Sauvegarder ailleurs (cloud, disque externe)
```
