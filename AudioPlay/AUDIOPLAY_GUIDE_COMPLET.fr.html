Touche Action Description

🔍 Recherche dans la Playlist

AudioPlay offre une fonctionnalité de recherche instantanée pour filtrer rapidement les chansons dans votre playlist.

  • Barre de recherche : Située au-dessus de la liste de lecture, tapez du texte pour rechercher instantanément
  • Sélecteur de type de recherche : Choisissez parmi trois options :
    • Nom de fichier : Recherche dans le nom des chansons
    • BPM : Recherche par valeur de tempo
    • Durée : Recherche par durée de la chanson (format "3:45")
  • Recherche instantanée : Les résultats se mettent à jour au fur et à mesure que vous tapez
  • Sélection automatique : Toutes les chansons correspondantes sont sélectionnées
  • Effacer la recherche :
    • Cliquez sur le bouton ✕ à droite du champ de recherche (devient vert au survol, rouge au clic)
    • Appuyez sur Échap
    • Effacez manuellement le texte
    Toutes ces actions reviennent à la liste complète et rendent le focus au ListView
💡 Astuce : Les raccourcis clavier sont automatiquement désactivés lorsque vous tapez dans la barre de recherche, évitant ainsi tout conflit avec votre saisie.

🎯 Fonctionnalités Avancées

🎼 BPM (Calcul)
Calcule automatiquement les battements par minute (BPM) d'une chanson :
  • Méthode Auto : Utilise Python + librosa si disponible (95%+ précision), sinon SoundTouch
  • Méthode Librosa : Utilise Python (très précis, requiert installation)
  • Méthode SoundTouch : Utilise l'algorithme intégré (précision ±75%)
Astuce : Le BPM calculé est sauvegardé dans les métadonnées du fichier et affiché dans la playlist.
🔄 Loop (Boucle)
Active/désactive la répétition d'une section de la chanson :
  1. Pendant la lecture, appuyez sur I au début de la section
  2. Appuyez sur O à la fin de la section
  3. Cliquez sur le bouton Loop pour activer la boucle
  4. La section se répète indéfiniment jusqu'à désactivation
Note : Le calcul BPM est bloqué pendant qu'une boucle est active. Désactivez la boucle d'abord.
🎲 Aléatoire (Random)
Active/désactive la lecture aléatoire. Quand activé, les chansons sont jouées dans un ordre aléatoire.

ℹ️ À Propos

🎧 Mode DJ

☑️ Mode Mixeur DJ (2 platines avec crossfader et contrôles DJ)
Active ou désactive le mode DJ professionnel d'AudioPlay.

Mode Simple (par défaut) :

  • Interface classique avec une seule playlist
  • Lecture linéaire des chansons
  • Contrôles audio de base (volume, égaliseur)

Mode DJ (2 platines) :

  • 🎚️ 2 platines indépendantes (Deck A et Deck B)
  • 🔀 Crossfader pour mixer entre les deux decks
  • 🎵 Contrôles de pitch (-50% à +50%) sur chaque deck
  • 🎼 Détection BPM automatique pour synchronisation
  • 🔄 Boutons Sync pour aligner automatiquement les tempos
  • 🎛️ Effets audio par deck (Phaser, Reverb, Echo)
  • 📍 Points Cue pour démarrer à un point précis
  • 📊 VU-mètres pour visualiser les niveaux audio
  • 📋 Playlist intégrée avec drag & drop vers les decks
Basculement automatique : Lorsque vous cochez ou décochez cette option et cliquez sur "Sauvegarder", AudioPlay bascule automatiquement entre le mode Simple et le mode DJ sans avoir à redémarrer l'application.
Conseil : Le mode DJ est idéal pour les DJ débutants ou confirmés qui souhaitent mixer deux pistes simultanément avec des fonctionnalités professionnelles.

🎼 Calcul BPM

Méthode de calcul BPM
Choisissez la méthode pour calculer les battements par minute :
  • Auto : Utilise librosa si Python est installé, sinon SoundTouch
  • Librosa (Python) : Très précis (95%+), nécessite Python + librosa
  • SoundTouch : Intégré, rapide, précision ±75%
Installation Python : AudioPlay peut installer automatiquement Python portable + librosa. Cliquez sur "Calculer BPM" et acceptez l'installation proposée.

🎧 Mode DJ - Guide d'Utilisation

Le mode DJ transforme AudioPlay en un véritable système de mixage professionnel avec deux platines indépendantes, un crossfader et des contrôles DJ avancés.

💡 Comment activer le mode DJ : Allez dans Paramètres → cochez "Mode Mixeur DJ (2 platines avec crossfader et contrôles DJ)" → cliquez sur Sauvegarder. AudioPlay basculera automatiquement en mode DJ.

🎛️ Interface du Mode DJ

Vue d'ensemble
Le mode DJ est divisé en 4 zones principales :
  • 🎧 Deck A (Gauche) : Platine gauche avec tous ses contrôles
  • 🎧 Deck B (Droite) : Platine droite avec tous ses contrôles
  • 🎚️ Zone Mixeur (Centre) : Crossfader et boutons de contrôle
  • 📋 Playlist (Bas) : Liste des morceaux avec gestion

🎵 Charger des Pistes

Méthode 1 : Drag & Drop depuis la Playlist
  1. Cliquez et maintenez sur un morceau dans la playlist
  2. Faites-le glisser vers la zone "Glissez une piste ici ⬇" du Deck A ou Deck B
  3. Relâchez pour charger le morceau sur le deck
Méthode 2 : Ajouter à la Playlist
  • Cliquez sur ➕ Ajouter pour ouvrir le menu
  • Choisissez "Ajouter un fichier" ou "Ajouter un répertoire"
  • Les morceaux ajoutés apparaissent dans la playlist

🎮 Contrôles des Decks

Contrôle Description
▶ Play Lance la lecture du morceau chargé sur le deck
⏸ Pause Met en pause la lecture (reprend au même point)
⏹ Stop Arrête la lecture et revient au début (ou au point Cue)
📍 Cue Définit un point de départ. Cliquez pendant la lecture pour marquer un point, cliquez à nouveau pour revenir à ce point
Barre de Position Affiche et contrôle la position dans le morceau. Cliquez pour naviguer rapidement

🎚️ Contrôles Audio par Deck

Contrôle Fonction
Volume Règle le volume du deck (0-100%). Chaque deck a son propre volume indépendant
Pitch Ajuste la vitesse de lecture de -50% à +50%. Change le tempo ET la hauteur tonale. Idéal pour synchroniser les BPM
BPM Affiche les battements par minute détectés automatiquement. Utile pour le mixage harmonique
📊 VU-Mètre Indicateur visuel en temps réel du niveau audio. Permet de voir l'intensité sonore

🔀 Le Crossfader

Fonction principale du Crossfader
Le crossfader est le cœur du mixage DJ. Il permet de faire une transition fluide entre les deux decks :
  • Position 0% (Gauche) : Seul le Deck A est audible
  • Position 50% (Centre) : Les deux decks sont audibles à volume égal
  • Position 100% (Droite) : Seul le Deck B est audible
Technique de mixage : Lancez un morceau sur Deck A (crossfader à gauche). Préparez le morceau suivant sur Deck B. Quand vous êtes prêt, déplacez progressivement le crossfader vers la droite pour effectuer la transition.

🔄 Synchronisation BPM (Sync)

Boutons Sync A→B et Sync B→A
Ces boutons permettent de synchroniser automatiquement les tempos :
  • Sync A→B : Ajuste automatiquement le pitch du Deck B pour correspondre au BPM du Deck A
  • Sync B→A : Ajuste automatiquement le pitch du Deck A pour correspondre au BPM du Deck B
Utilisation : Chargez deux morceaux, lancez-les, puis cliquez sur Sync pour qu'ils jouent au même tempo. Idéal pour un mixage harmonieux !

🎛️ Effets Audio par Deck

Chaque deck dispose de 3 effets activables individuellement :
Effet Description
🌀 Phaser Effet de balayage de phase qui crée un son "spatial" et ondulant. Parfait pour les transitions
🔊 Reverb Réverbération qui ajoute de l'écho et de la profondeur au son. Simule l'acoustique d'une salle
📢 Echo Répétition du son qui crée un effet d'écho. Utile pour les fins de phrases musicales
Astuce : Cochez les effets pendant la lecture pour les activer en temps réel. Les effets sont indépendants par deck, vous pouvez donc avoir Phaser sur A et Reverb sur B simultanément.

💡 Conseils pour Bien Mixer

Workflow de mixage recommandé :
  1. 📋 Chargez votre playlist avec vos morceaux
  2. 🎵 Glissez un premier morceau sur Deck A et lancez-le (crossfader à gauche)
  3. 🎵 Glissez le morceau suivant sur Deck B
  4. 🔊 Réglez le volume du Deck B pour le pré-écouter (crossfader toujours à gauche = inaudible pour le public)
  5. 🔄 Utilisez le bouton Sync pour aligner les BPM
  6. 📍 Définissez un point Cue sur Deck B pour démarrer au bon moment
  7. ▶ Lancez Deck B et déplacez progressivement le crossfader vers le centre puis vers la droite
  8. 🔁 Répétez : préparez maintenant le morceau suivant sur Deck A pendant que Deck B joue
⚠️ Important : Le mode DJ sauvegarde automatiquement votre playlist. Elle sera rechargée au prochain démarrage du mode DJ.
🎓 Pour aller plus loin :
  • Expérimentez avec les effets audio pour créer des transitions uniques
  • Utilisez les points Cue pour démarrer pile sur le premier beat d'un morceau
  • Observez les VU-mètres pour éviter la saturation audio
  • Mixez des morceaux avec des BPM proches pour des transitions plus naturelles

✨ Fonctionnalités Avancées

🎤 Karaoke CDG

Lecture de fichiers CD+G (Karaoke)
AudioPlay supporte nativement les fichiers karaoke :
  • Ajoutez un fichier audio avec un fichier .cdg du même nom
  • La fenêtre karaoke s'ouvre automatiquement
  • Affichage des paroles synchronisées

🔄 Normalisation de Volume

Égalisation automatique du volume
La normalisation analyse et ajuste le volume de chaque chanson :
  • Calcul du niveau RMS (Root Mean Square)
  • Détection des pics audio
  • Application d'un gain correctif
  • Pas de modification permanente des fichiers
Avantages : Plus besoin d'ajuster le volume entre les chansons. L'écoute est homogène et confortable.

🎵 Métronome Synchronisé

Pratique musicale avec métronome
Le métronome d'AudioPlay se synchronise avec le BPM détecté :
  • Son audible : Tic-tac sur chaque battement
  • Indicateur visuel : LED clignotante synchronisée
  • Mesures configurables : 1 à 16 temps par mesure
  • Accentuation : Premier temps de chaque mesure accentué
Musiciens : Parfait pour pratiquer un instrument ou chanter en gardant le tempo précis de la chanson.

✂️ Suppression des Silences

Détection et suppression des silences
AudioPlay peut automatiquement :
  • Début de piste : Saute les silences initiaux
  • Fin de piste : Passe à la chanson suivante sans attendre le silence final
  • Seuil réglable : Détection intelligente basée sur le niveau audio
Résultat : Les chansons démarrent et se terminent précisément, sans temps mort.

Calcul BPM Rapide

Thème Personnalisé

⚠️ Points d'Attention

Modification de Métadonnées
Les modifications de métadonnées sont permanentes. Vérifiez avant de sauvegarder.
Calcul BPM et Boucle
Vous ne pouvez pas calculer le BPM pendant qu'une boucle est active. Désactivez d'abord la boucle.
Fichiers Protégés
Si un fichier est en lecture seule ou protégé, les métadonnées ne peuvent pas être modifiées.

🔧 Dépannage

❓ Problèmes Courants

🔇 Pas de son

  • Vérifiez que le volume n'est pas à 0%
  • Vérifiez que le mode Mute n'est pas activé
  • Vérifiez le volume système de Windows
  • Testez avec un autre fichier audio

❌ Fichier ne s'ouvre pas

  • Vérifiez que le format est supporté
  • Vérifiez que le fichier n'est pas corrompu
  • Vérifiez les permissions du fichier
  • Essayez de copier le fichier dans un autre dossier

🐌 Calcul BPM lent

  • Le calcul BPM avec SoundTouch est rapide
  • Le calcul avec librosa (Python) est plus précis mais plus lent
  • Vous pouvez annuler avec Échap (avec confirmation) ou Ctrl + Espace (sans confirmation)
  • Changez la méthode dans Paramètres > Calcul BPM

🎨 Thème ne s'applique pas

  • Assurez-vous d'avoir cliqué sur "Appliquer"
  • Fermez et rouvrez les autres fenêtres (Métadonnées, Paramètres)
  • Vérifiez que le thème existe dans le dossier Themes/

🌍 Changement de langue ne fonctionne pas

  • Fermez complètement AudioPlay
  • Relancez l'application
  • La langue s'applique au démarrage
