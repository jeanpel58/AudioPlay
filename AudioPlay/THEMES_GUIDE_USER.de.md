# 🎨 AudioPlay Farbthemen - Benutzerhandbuch

## 🎉 Neue Funktionen!

AudioPlay verfügt jetzt über ein vollständiges Farbthemen-Verwaltungssystem. Sie können das Aussehen Ihres Audio-Players vollständig anpassen!

## 🚀 Schnellstart

### Wie ändert man Themen?

1. Öffnen Sie **Einstellungen** (Menü oder Einstellungsschaltfläche)
2. Gehen Sie zum Abschnitt **"Schnittstellenfarben"**
3. Verwenden Sie das Dropdown-Menü **"Thema auswählen"**
4. Wählen Sie aus:
   - 🎨 **Standard** - Ursprüngliches AudioPlay-Thema (hellblau)
   - 🌙 **Dunkel** - Nachtmodus mit dunkelgrauem Hintergrund
   - ☀️ **Sonne** - Helles und energiegeladenes Gelb
   - 🌊 **Ozean** - Beruhigendes Himmelblau
   - 🍂 **Herbst** - Warme Goldtöne

Das Thema wird **sofort** auf die gesamte Benutzeroberfläche angewendet!

---

## ✨ Erstellen Sie Ihr eigenes Thema

### Schritt 1: Farben anpassen

1. In **Einstellungen** > **Schnittstellenfarben**
2. Klicken Sie auf **"Anpassen..."**
3. Ein Fenster öffnet sich mit allen anpassbaren Elementen:
   - Formular-Hintergründe
   - Steuerungs-Hintergründe
   - Schaltflächenfarben
   - Wiedergabelistenfarben
   - Und vieles mehr!

### Schritt 2: Wählen Sie Ihre Farben

1. Wählen Sie ein Element aus der Liste
2. Klicken Sie auf **"Farbe wählen..."**
3. Verwenden Sie den Farbwähler
4. Klicken Sie auf **"Anwenden"**, um das Ergebnis in Echtzeit zu sehen
5. Fahren Sie fort, bis Sie das gewünschte Aussehen erhalten
6. Klicken Sie auf **"OK"**, wenn Sie zufrieden sind

### Schritt 3: Speichern Sie Ihr Thema

1. Klicken Sie auf **"Speichern als..."**
2. Geben Sie einen Namen für Ihr Thema ein (z. B. "Mein lila Thema")
3. Bestätigen
4. Ihr Thema ist jetzt in der Liste!

---

## 🗑️ Ein Thema löschen

1. Wählen Sie das zu löschende Thema aus der Dropdown-Liste
2. Klicken Sie auf **"Löschen"**
3. Bestätigen Sie das Löschen
4. Das **"Standard"**-Thema wird automatisch reaktiviert

⚠️ **Hinweis**: Das "Standard"-Thema kann nicht gelöscht werden.

---

## 🔄 Farben zurücksetzen

Klicken Sie jederzeit auf **"Zurücksetzen"**, um zu den Standardfarben von AudioPlay zurückzukehren.

Dies löscht Ihre benutzerdefinierten Themen nicht, Sie können sie später noch verwenden.

---

## 🎨 Anpassbare Elemente

Sie können die Farben ändern von:

| Element | Beschreibung |
|---------|--------------|
| 🖼️ **Formular-Hintergründe** | Hintergrundfarbe der Fenster |
| 🎛️ **Steuerungs-Hintergründe** | Steuerungs- und Panelbereiche |
| 🔤 **Steuerungstext** | Allgemeine Textfarbe |
| 🔘 **Schaltflächen-Hintergründe** | Schaltflächenhintergrund |
| 📝 **Schaltflächentext** | Text auf Schaltflächen |
| 📋 **Listen-Hintergrund** | Songlist |
| 📄 **Listentext** | Text in der Liste |
| 📊 **Listen-Kopfzeile** | Spaltenkopfzeile |
| ✅ **Auswahl** | Hervorhebung ausgewählter Elemente |
| 📝 **Textfelder** | Eingabefelder |
| 📦 **Gruppen** | Abschnittstitel |
| 🎚️ **Schieberegler** | Lautstärke- und Positionsleisten |

## 💾 Teilen Sie Ihre Themen

### Ein Thema zum Teilen exportieren

Themen werden als `.theme`-Dateien gespeichert in:
```
%AppData%\AudioPlay\Themes\
```

Um eines Ihrer Themen zu teilen:
1. Öffnen Sie diesen Ordner (fügen Sie den obigen Pfad im Windows Explorer ein)
2. Kopieren Sie die entsprechende `.theme`-Datei (z. B. `Mein lila Thema.theme`)
3. Senden Sie diese Datei an einen anderen Benutzer

### Ein empfangenes Thema importieren

Wenn Sie eine `.theme`-Datei von einem anderen Benutzer erhalten:
1. Öffnen Sie den Ordner `%AppData%\AudioPlay\Themes\`
2. Fügen Sie die empfangene `.theme`-Datei dort ein
3. Starten Sie AudioPlay neu oder aktualisieren Sie die Einstellungsliste
4. Das neue Thema erscheint in der Dropdown-Liste

## 🎨 Vorinstallierte Themen

AudioPlay enthält mehrere gebrauchsfertige Themen:

### Standard
Das ursprüngliche AudioPlay-Thema mit beruhigenden hellblauen Tönen.

### Dunkel
Ein Thema mit dunkelgrauem Hintergrund, perfekt für die Arbeit in dunklen Umgebungen und zur Reduzierung der Augenbelastung.

### Sonne
Helle, warme Gelbtöne für eine energiegeladene und sonnige Benutzeroberfläche.

### Ozean
Hellblaue Nuancen, inspiriert vom Ozean, für eine frische und entspannende Atmosphäre.

### Herbst
Goldene, warme Farben, die an Herbstblätter erinnern.

## 💡 Tipps

- **In Echtzeit testen**: Verwenden Sie die Schaltfläche "Anwenden" im Themeneditor, um Ihre Änderungen sofort zu sehen
- **Regelmäßig speichern**: Speichern Sie Ihre Änderungen unter einem neuen Namen, bevor Sie weiter experimentieren
- **Klar benennen**: Geben Sie Ihren Themen beschreibende Namen (z. B. "Sternennacht", "Pastellrosa"), um sie leicht zu finden
- **Wichtiger Kontrast**: Stellen Sie sicher, dass der Text auf den von Ihnen gewählten Hintergründen lesbar bleibt

## 🔧 Fehlerbehebung

### Mein Thema erscheint nicht in der Liste
- Überprüfen Sie, ob die `.theme`-Datei in `%AppData%\AudioPlay\Themes\` liegt
- Starten Sie AudioPlay neu
- Die Datei muss die Erweiterung `.theme` haben (nicht `.theme.txt`)

### Farben sind nach der Änderung seltsam
- Verwenden Sie die Schaltfläche "Zurücksetzen", um zum Standardthema zurückzukehren
- Löschen Sie das problematische Thema und erstellen Sie es neu

### Ich kann ein Thema nicht löschen
- Das "Standard"-Thema kann aus Sicherheitsgründen nicht gelöscht werden
- Stellen Sie sicher, dass Sie nicht versuchen, ein aktives Thema zu ändern/löschen

### Text ist auf einigen Hintergründen unleserlich
- In **"Anpassen..."** passen Sie die Textfarben an
- Allgemeine Regel: heller Text auf dunklem Hintergrund, dunkler Text auf hellem Hintergrund
- Verwenden Sie die Schaltfläche **"Anwenden"** zum Überprüfen
