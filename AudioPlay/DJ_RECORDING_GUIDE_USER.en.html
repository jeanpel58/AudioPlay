🎙️ Recording Guide - DJ Mode

Record your mix sessions with ease

📋 Overview

The DJ recording feature allows you to capture your mix sessions in real-time, in multiple high-quality audio formats. Whether you're creating a podcast, a DJ set, or simply want to keep your best mixes, this feature is designed for you.

🚀 Quick Start

1. Preparation

  • Load at least one track on either deck (A or B)
  • Select the desired recording format from the dropdown list
  • The default format is MP3 320 kbps

2. Starting the Recording

Step by step:

  1. Click the ⬤ REC button
  2. Select the destination folder for your mix
  3. A confirmation message displays the file name
  4. The button changes to ⬛ STOP
  5. Recording duration displays in real-time
💡 Tip: The destination folder is remembered between sessions. You only need to select it once!

3. Recording in Progress

During recording:

  • Mix normally with your two decks
  • Use the crossfader, effects, pitch
  • Duration displays in HH:MM:SS format
  • All sound output from your system is captured
⚠️ Warning: Recording captures ALL audio output from your system. Avoid system notifications or other unwanted sounds during recording.

4. Stopping the Recording

  • Click the ⬛ STOP button
  • A confirmation message shows total duration and file location
  • You can open the folder containing your mix directly

📁 File Organization

File naming:

Recordings are automatically named with a timestamp:

DJMix_YYYY-MM-DD_HH-MM-SS.extension

Example: DJMix_2026-06-02_15-30-45.mp3

🛠️ Tips and Best Practices

Optimal Quality

  • For archiving: Use WAV format
  • For sharing: MP3 320 kbps offers excellent compromise
  • For podcasts: MP3 192 kbps is sufficient

Disk Space

💡 Size estimation (for 1 hour):
  • WAV: ~600 MB
  • MP3 320 kbps: ~144 MB
  • MP3 192 kbps: ~86 MB
  • MP3 128 kbps: ~58 MB

Performance

  • Recording doesn't affect playback performance
  • MP3 encoding is optimized for real-time use
  • Ensure you have enough disk space available

❓ Troubleshooting

Recording Won't Start

Possible solutions:

  • Check that at least one track is loaded
  • Ensure you have write permissions in the destination folder
  • Check that sufficient disk space is available

No Sound Recorded

Possible solutions:

  • Check that the master volume is not zero
  • Check Windows audio settings (output device)
  • Restart AudioPlay and try again

File is Corrupted

Possible solutions:

  • Stop recording properly using the STOP button
  • Don't close AudioPlay during recording
  • Check your hard drive integrity

🎓 Advanced Techniques

Long Set Recording

For multi-hour sessions:

  • Prefer MP3 320 kbps format to save space
  • Monitor available disk space
  • Plan breaks to save and restart

Post-Production

After recording:

  • Normalize volume with audio software (Audacity, etc.)
  • Add ID3 tags to organize your mixes
  • Trim silence at beginning and end if needed
