Start Position Adjustment (Pre-roll)

Move the start of the first track slightly earlier to avoid truncation
What is it?

Pre-roll shifts the start point of track 1 backward by a small number of seconds before the TOC position. This recovers a short interval of silence and prevents the first note from being cut.

Why use pre-roll?

On some discs, the TOC marks the track start very close to the first musical event. Pre-roll provides a safety margin that improves perceived audio quality.

How it works

Enter a value in seconds (e.g. 1.75). The extractor will subtract this duration from the TOC start of track 1 and begin reading earlier.

Allowed values: 0.5s to 4.0s. Default: 1.75s.

Tips

  • Start with 1.5–2.0s if the first note is too close to the TOC.
  • If the disc already has leading silence, choose a smaller value.
  • Pre-roll applies only to the first track to avoid affecting transition detection.

Visual example

TOC  |----> [pre-roll]  ---> actual track start

Support

If you observe undesired side effects (e.g., live track fade-ins), reduce the value or contact support.
