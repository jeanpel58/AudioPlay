🔍 Playlist Search

AudioPlay offers an instant search feature to quickly filter songs in your playlist.

  • Search bar: Located above the playlist, type text to search instantly
  • Search type selector: Choose from three options:
    • File Name: Search in song names
    • BPM: Search by tempo value
    • Duration: Search by song duration (format "3:45")
  • Instant search: Results update as you type
  • Automatic selection: All matching songs are selected
  • Clear search:
    • Click the ✕ button to the right of the search field (turns green on hover, red on click)
    • Press Esc
    • Manually clear the text
    All these actions return to the full list and restore focus to the ListView
💡 Tip: Keyboard shortcuts are automatically disabled when typing in the search bar, preventing any conflicts with your input.

🎯 Advanced Features

🎼 BPM (Calculate)
Automatically calculates beats per minute (BPM) for a song:
  • Auto Method: Uses Python + librosa if available (95%+ accuracy), otherwise SoundTouch
  • Librosa Method: Uses Python (very accurate, requires installation)
  • SoundTouch Method: Uses built-in algorithm (±75% accuracy)
Tip: Calculated BPM is saved in file metadata and displayed in the playlist.
🔄 Loop
Enables/disables repeating a section of the song:
  1. During playback, press I at the section start
  2. Press O at the section end
  3. Click the Loop button to activate looping
  4. The section repeats indefinitely until deactivated
Note: BPM calculation is blocked while a loop is active. Disable the loop first.
🎲 Random
Enables/disables random playback. When enabled, songs are played in random order.

🎧 DJ Mode

☑️ DJ Mixer Mode (2 decks with crossfader and DJ controls)
Enables or disables AudioPlay's professional DJ mode.

Simple Mode (default):

  • Classic interface with a single playlist
  • Linear song playback
  • Basic audio controls (volume, equalizer)

DJ Mode (2 decks):

  • 🎚️ 2 independent decks (Deck A and Deck B)
  • 🔀 Crossfader to mix between both decks
  • 🎵 Pitch controls (-50% to +50%) on each deck
  • 🎼 Automatic BPM detection for synchronization
  • 🔄 Sync buttons to automatically align tempos
  • 🎛️ Audio effects per deck (Phaser, Reverb, Echo)
  • 📍 Cue points to start at a precise position
  • 📊 VU meters to visualize audio levels
  • 📋 Integrated playlist with drag & drop to decks
Automatic switching: When you check or uncheck this option and click "Save", AudioPlay automatically switches between Simple and DJ mode without needing to restart the application.
Tip: DJ mode is ideal for beginner or experienced DJs who want to mix two tracks simultaneously with professional features.

🎧 DJ Mode - User Guide

DJ Mode transforms AudioPlay into a professional mixing system with two independent decks, a crossfader, and advanced DJ controls.

💡 How to enable DJ Mode: Go to Settings → check "DJ Mixer Mode (2 decks with crossfader and DJ controls)" → click Save. AudioPlay will automatically switch to DJ mode.

🎛️ DJ Mode Interface

Overview
DJ Mode is divided into 4 main areas:
  • 🎧 Deck A (Left): Left turntable with all its controls
  • 🎧 Deck B (Right): Right turntable with all its controls
  • 🎚️ Mixer Zone (Center): Crossfader and control buttons
  • 📋 Playlist (Bottom): Track list with management

🎵 Loading Tracks

Method 1: Drag & Drop from Playlist
  1. Click and hold on a track in the playlist
  2. Drag it to the "Drag track here ⬇" area of Deck A or Deck B
  3. Release to load the track onto the deck
Method 2: Add to Playlist
  • Click ➕ Add to open the menu
  • Choose "Add a file" or "Add a folder"
  • Added tracks appear in the playlist

🎮 Deck Controls

Control Description
▶ Play Starts playback of the loaded track on the deck
⏸ Pause Pauses playback (resumes at the same point)
⏹ Stop Stops playback and returns to the beginning (or Cue point)
📍 Cue Sets a start point. Click during playback to mark a point, click again to return to it
Position Bar Displays and controls position in the track. Click to navigate quickly

🎚️ Audio Controls per Deck

Control Function
Volume Adjusts deck volume (0-100%). Each deck has its own independent volume
Pitch Adjusts playback speed from -50% to +50%. Changes both tempo AND pitch. Ideal for BPM synchronization
BPM Displays automatically detected beats per minute. Useful for harmonic mixing
📊 VU Meter Real-time visual indicator of audio level. Shows sound intensity

🔀 The Crossfader

Main Crossfader Function
The crossfader is the heart of DJ mixing. It allows smooth transition between the two decks:
  • Position 0% (Left): Only Deck A is audible
  • Position 50% (Center): Both decks are audible at equal volume
  • Position 100% (Right): Only Deck B is audible
Mixing technique: Start a track on Deck A (crossfader to the left). Prepare the next track on Deck B. When ready, gradually move the crossfader to the center then to the right to perform the transition.

🔄 BPM Synchronization (Sync)

Sync A→B and Sync B→A Buttons
These buttons allow automatic tempo synchronization:
  • Sync A→B: Automatically adjusts Deck B's pitch to match Deck A's BPM
  • Sync B→A: Automatically adjusts Deck A's pitch to match Deck B's BPM
Usage: Load two tracks, start them, then click Sync to make them play at the same tempo. Perfect for harmonious mixing!

🎛️ Audio Effects per Deck

Each deck has 3 individually activatable effects:
Effect Description
🌀 Phaser Phase sweep effect that creates a "spatial" and undulating sound. Perfect for transitions
🔊 Reverb Reverberation that adds echo and depth to the sound. Simulates room acoustics
📢 Echo Sound repetition that creates an echo effect. Useful for musical phrase endings
Tip: Check the effects during playback to activate them in real time. Effects are independent per deck, so you can have Phaser on A and Reverb on B simultaneously.

💡 Tips for Good Mixing

Recommended mixing workflow:
  1. 📋 Load your playlist with your tracks
  2. 🎵 Drag a first track to Deck A and start it (crossfader to the left)
  3. 🎵 Drag the next track to Deck B
  4. 🔊 Adjust Deck B's volume to preview it (crossfader still left = inaudible to the audience)
  5. 🔄 Use the Sync button to align BPMs
  6. 📍 Set a Cue point on Deck B to start at the right moment
  7. ▶ Start Deck B and gradually move the crossfader to the center then to the right
  8. 🔁 Repeat: now prepare the next track on Deck A while Deck B is playing
⚠️ Important: DJ mode automatically saves your playlist. It will be reloaded the next time you start DJ mode.
🎓 To go further:
  • Experiment with audio effects to create unique transitions
  • Use Cue points to start right on a track's first beat
  • Watch the VU meters to avoid audio saturation
  • Mix tracks with close BPMs for more natural transitions

🔧 Troubleshooting

❓ Common Issues

🔇 No Sound

  • Check that volume is not at 0%
  • Check that Mute mode is not enabled
  • Check Windows system volume
  • Test with another audio file

❌ File Won't Open

  • Check that the format is supported
  • Check that the file is not corrupted
  • Check file permissions
  • Try copying the file to another folder

🐌 Slow BPM Calculation

  • BPM calculation with SoundTouch is fast
  • Calculation with librosa (Python) is more accurate but slower
  • You can cancel with Esc (with confirmation) or Ctrl + Space (without confirmation)
  • Change method in Settings > BPM Calculation

🎨 Theme Not Applying

  • Make sure you clicked "Apply"
  • Close and reopen other windows (Metadata, Settings)
  • Check that the theme exists in the Themes/ folder

🌍 Language Change Not Working

  • Completely close AudioPlay
  • Restart the application
  • Language is applied at startup
