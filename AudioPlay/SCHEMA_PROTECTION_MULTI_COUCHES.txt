═══════════════════════════════════════════════════════════════════════════
						RÉSUMÉ DES 5 PROTECTIONS
═══════════════════════════════════════════════════════════════════════════

[PROTECTION #0] - initialisationEnCours dans TrackBar_Scroll
	↳ Bloque les événements Scroll pendant l'application des paramètres
	↳ Évite les boucles infinies et les sauvegardes intempestives

[PROTECTION #1] - FormParametres récupère depuis Form1
	↳ FormParametres ne hardcode JAMAIS de valeurs
	↳ Lecture depuis form1Instance.dernierVolume/Basses/Aigues

[PROTECTION #2] - Flag ParametresAudioModifies
	↳ FormParametres signale à Form1 s'il a modifié les paramètres audio
	↳ Permet à Form1 de savoir s'il doit recharger ou restaurer

[PROTECTION #3] - Backup/Restore dans Button_Parametres_Click
	↳ Sauvegarde des valeurs AVANT ChargerParametres()
	↳ Restauration si ParametresAudioModifies = False
	↳ Annule tout écrasement accidentel

[PROTECTION #4] - initialisationEnCours dans AppliquerParametresAuxControles
	↳ Bloque les événements Scroll pendant la mise à jour des TrackBars
	↳ Évite que TrackBar.Value déclenche Scroll → SauvegarderParametres()

ANCIEN CODE (BUGUÉ) :
	FormParametres.ButtonSauvegarder_Click()
		"Basses=0",         ← HARDCODÉ ❌
		"Aigues=0",         ← HARDCODÉ ❌
		File.WriteAllLines(parametres.txt)

	Form1.Button_Parametres_Click()
		ChargerParametres()           ← Lit Basses=0, Aigues=0 ❌
		AppliquerParametresAuxControles()  ← Applique 0 aux TrackBars ❌
		→ L'utilisateur perd ses réglages ! ❌


NOUVEAU CODE (PROTÉGÉ) :
	FormParametres.ButtonSauvegarder_Click()
		volumeActuel = form1Instance.dernierVolume     ← LIT depuis Form1 ✅
		bassesActuelles = form1Instance.dernieresBasses ← LIT depuis Form1 ✅
		aiguesActuelles = form1Instance.dernieresAigues ← LIT depuis Form1 ✅
		ParametresAudioModifies = False                 ← SIGNALE pas touché ✅
		File.WriteAllLines(parametres.txt)

	Form1.Button_Parametres_Click()
		volumeAvant = dernierVolume                     ← BACKUP ✅
		bassesAvant = dernieresBasses                   ← BACKUP ✅
		aiguesAvant = dernieresAigues                   ← BACKUP ✅
		ChargerParametres()
		IF NOT dlg.ParametresAudioModifies THEN         ← CHECK ✅
			dernierVolume = volumeAvant                 ← RESTORE ✅
			dernieresBasses = bassesAvant               ← RESTORE ✅
			dernieresAigues = aiguesAvant               ← RESTORE ✅
		END IF
		AppliquerParametresAuxControles()
		→ L'utilisateur conserve ses réglages ! ✅
