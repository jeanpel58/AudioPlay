🎧 AudioPlay - Guide du Mode DJ

Mode DJ Professionnel
Transformez AudioPlay en station de mixage DJ complète avec 2 platines, crossfader, effets et enregistrement !

⚙️ Activation du Mode DJ

  1. Ouvrez Paramètres dans AudioPlay
  2. Cochez "Mode Mixeur DJ"
  3. Cliquez sur Sauvegarder
  4. Redémarrez AudioPlay
  5. L'interface DJ s'ouvre automatiquement

🎛️ Fonctionnalités Principales

1. 🎵 Contrôle des Platines (Decks)

Deck A et Deck B - Deux platines indépendantes

  • Charger Piste : Chargez vos fichiers audio (MP3, WAV, FLAC...)
  • Play/Pause/Stop : Contrôles de lecture standard
  • Cue : Définit et retourne au point de départ
  • Volume : Contrôle de volume individuel par platine
  • Position : TrackBar interactif pour navigation et scratch

2. 🎚️ Crossfader & Mixage

Crossfader central avec trois modes de courbe :

  • Linéaire : Transition progressive (débutants)
  • DJ : Courbe standard professionnelle
  • Sharp : Transition rapide (scratch/battle)

VU-Mètres : Affichage LED style avec peak-hold pour chaque deck

3. 🎵 Pitch & Tempo

  • Pitch Bend : Ajustement ±8% en temps réel
  • Détection BPM : Analyse automatique du tempo
  • Bouton SYNC : Synchronisation automatique entre les deux decks
  • Affichage BPM : Tempo affiché en temps réel

4. 🌊 Waveform (Forme d'onde)

  • Visualisation : Amplitude audio affichée en temps réel
  • Marqueurs de Cue : Points rouges pour les HotCues
  • Indicateur de position : Ligne jaune montrant la lecture actuelle
  • Navigation par clic : Cliquez sur la waveform pour sauter à une position

5. 🔴 HotCues (8 par deck)

8 points de repère avec couleurs distinctes :

Action Raccourci Description
Déclencher Clic gauche Saute au HotCue
Définir Shift + Clic Enregistre la position actuelle
Supprimer Clic droit Efface le HotCue

Couleurs : Rouge, Orange, Jaune, Vert, Cyan, Bleu, Magenta, Rose

6. 🔁 Loop (Boucles Audio)

Boucles automatiques basées sur le BPM :

  • 2 Beats 4 Beats 8 Beats 16 Beats

Boucles manuelles :

  • Loop In : Définit le début de la boucle
  • Loop Out : Définit la fin de la boucle
  • Loop On/Off : Active/désactive la boucle
Astuce : La lecture revient automatiquement au début quand la boucle est active.

7. 🎙️ Enregistrement de Mix

  • Format WAV : Qualité audio haute fidélité
  • Capture complète : Mixage des deux decks + effets
  • Nommage automatique : Mix_YYYYMMDD_HHmmss.wav
  • Emplacement : Documents\AudioPlay\Recordings\
  • Indicateur de durée : Affichage en temps réel
Utilisation : Cliquez sur ● REC pour démarrer, ■ STOP pour arrêter.

8. 🎯 Auto-Cue

  • Détection automatique : Trouve le premier signal audio significatif
  • Suppression des silences : Ignore les blancs au début
  • Seuil adaptatif : Calcul automatique selon le niveau RMS
  • Activation optionnelle : Cochez/décochez selon vos besoins
Gain de temps : Les pistes démarrent instantanément au bon moment !

9. 🎹 Sampler (8 Pads)

8 pads indépendants pour effets sonores :

  • Chargement : Clic droit sur un pad → Choisir un fichier audio
  • Déclenchement : Clic gauche pour jouer
  • Lecture simultanée : Plusieurs pads peuvent jouer en même temps
  • Exemples : Sirènes, voix, drums, scratches, airhorns...

10. 🎨 Effets Audio

Effets individuels par deck :

  • Phaser : Effet de balayage de phase spatial
  • Reverb : Réverbération (salle, ambiance)
  • Echo : Écho/Delay réglable

Cochez/décochez les cases pour activer/désactiver. Les effets peuvent être combinés !

🎮 Workflow de Base

  1. Charger une piste sur le Deck A
  2. Définir un Cue au point de départ souhaité
  3. Lancer la lecture sur le Deck A
  4. Préparer le Deck B pendant que A joue
  5. Ajuster le tempo avec Pitch et SYNC
  6. Mixer avec le crossfader pour passer de A à B
  7. Ajouter des effets pour enrichir le mix
  8. Utiliser les HotCues pour des transitions rapides
  9. Enregistrer votre mix avec le bouton REC

⌨️ Raccourcis Clavier Principaux

Raccourci Action
Espace Play/Pause Deck A
Shift + Espace Play/Pause Deck B
C Cue Deck A
1-8 Déclencher HotCues Deck A
Shift + 1-8 Définir HotCues Deck A
F1-F8 Déclencher HotCues Deck B
L Loop On/Off Deck A
Y SYNC (synchroniser les decks)
Ctrl + R Démarrer/Arrêter Enregistrement
Q/W/E Effets Deck A (Phaser/Reverb/Echo)
← / → Déplacer Crossfader
Note : Pour plus de raccourcis, consultez le fichier MODE_DJ_KEYBOARD_SHORTCUTS.md dans la documentation.

💡 Astuces Pro

  • Beat Matching : Utilisez la waveform pour aligner visuellement les beats
  • HotCues stratégiques : Placez des cues aux points clés (intro, drop, outro)
  • Loops créatifs : Utilisez les boucles courtes pour construire des transitions
  • Auto-Cue : Activez-le pour gagner du temps lors du calage
  • Enregistrement : Lancez REC avant de commencer pour capturer tout votre set
  • Sampler : Préparez des effets sonores pour ajouter du dynamisme
  • VU-Mètres : Gardez les niveaux dans la zone verte/jaune (évitez le rouge)

⚠️ Dépannage

Problèmes Courants

  • Pas de son : Vérifiez les volumes de chaque deck et le crossfader
  • SYNC ne fonctionne pas : Assurez-vous que les BPM sont détectés (chargez les pistes d'abord)
  • Enregistrement ne démarre pas : Vérifiez les permissions du dossier Documents
  • Waveform ne s'affiche pas : Le fichier doit être complètement chargé
  • HotCues ne sauvegardent pas : Ils sont actifs pendant la session uniquement
