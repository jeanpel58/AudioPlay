## 🚀 Quick Start / Démarrage rapide

### English
1. Open **Settings**
2. Go to **"Interface colors"**
3. Select a theme from the dropdown menu
4. Click **"Save"** to apply

### Français
1. Ouvrez **Paramètres**
2. Allez dans **"Couleurs de l'interface"**
3. Sélectionnez un thème dans le menu déroulant
4. Cliquez sur **"Sauvegarder"** pour appliquer

### Español
1. Abra **Configuración**
2. Vaya a **"Colores de la interfaz"**
3. Seleccione un tema del menú desplegable
4. Haga clic en **"Guardar"** para aplicar

### Deutsch
1. Öffnen Sie **Einstellungen**
2. Gehen Sie zu **"Schnittstellenfarben"**
3. Wählen Sie ein Thema aus dem Dropdown-Menü
4. Klicken Sie auf **"Speichern"**, um es anzuwenden

### Italiano
1. Apri **Impostazioni**
2. Vai a **"Colori dell'interfaccia"**
3. Seleziona un tema dal menu a discesa
4. Fai clic su **"Salva"** per applicare
