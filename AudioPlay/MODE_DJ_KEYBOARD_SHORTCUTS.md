## 📋 Implémentation dans FormDJ.vb

```vb
Protected Overrides Function ProcessCmdKey(ByRef msg As Message, keyData As Keys) As Boolean
	Select Case keyData
		' Play/Pause
		Case Keys.Space
			ButtonPlayDeckA.PerformClick()
			Return True
		Case Keys.Shift Or Keys.Space
			ButtonPlayDeckB.PerformClick()
			Return True

		' Cue
		Case Keys.C
			ButtonCueDeckA.PerformClick()
			Return True
		Case Keys.Shift Or Keys.C
			ButtonCueDeckB.PerformClick()
			Return True

		' HotCues Deck A (1-8)
		Case Keys.D1 To Keys.D8
			Dim index = CInt(keyData) - Keys.D1 + 1
			If Control.ModifierKeys = Keys.Shift Then
				' Définir hotcue
				hotcueManagerDeckA.SetHotCue(index, fichierAudioDeckA.CurrentTime)
				HotCuePanelDeckA.RefreshDisplay()
			ElseIf Control.ModifierKeys = Keys.Control Then
				' Supprimer hotcue
				hotcueManagerDeckA.RemoveHotCue(index)
				HotCuePanelDeckA.RefreshDisplay()
			Else
				' Déclencher hotcue
				Dim hotcue = hotcueManagerDeckA.GetHotCue(index)
				If hotcue IsNot Nothing AndAlso fichierAudioDeckA IsNot Nothing Then
					fichierAudioDeckA.CurrentTime = hotcue.Position
				End If
			End If
			Return True

		' HotCues Deck B (F1-F8)
		Case Keys.F1 To Keys.F8
			Dim index = CInt(keyData) - Keys.F1 + 1
			' ... (similaire à Deck A)
			Return True

		' Enregistrement
		Case Keys.Control Or Keys.R
			ButtonRecord.PerformClick()
			Return True

		' Sync
		Case Keys.Y
			ButtonSync.PerformClick()
			Return True

		' Loop Deck A
		Case Keys.L
			ButtonLoopToggleDeckA.PerformClick()
			Return True
		Case Keys.I
			ButtonLoopInDeckA.PerformClick()
			Return True
		Case Keys.O
			ButtonLoopOutDeckA.PerformClick()
			Return True

		' Effets Deck A
		Case Keys.Q
			CheckBoxPhaserDeckA.Checked = Not CheckBoxPhaserDeckA.Checked
			Return True
		Case Keys.W
			CheckBoxReverbDeckA.Checked = Not CheckBoxReverbDeckA.Checked
			Return True
		Case Keys.E
			CheckBoxEchoDeckA.Checked = Not CheckBoxEchoDeckA.Checked
			Return True

		' Crossfader
		Case Keys.Left
			TrackBarCrossfader.Value = Math.Max(0, TrackBarCrossfader.Value - 5)
			Return True
		Case Keys.Right
			TrackBarCrossfader.Value = Math.Min(100, TrackBarCrossfader.Value + 5)
			Return True
		Case Keys.Up
			TrackBarCrossfader.Value = 50 ' Centre
			Return True

		' ... (ajouter tous les autres raccourcis)
	End Select

	Return MyBase.ProcessCmdKey(msg, keyData)
End Function
```

---

## 📝 Notes d'Implémentation

1. **Surcharger `ProcessCmdKey`** dans FormDJ.vb pour capturer les touches
2. **Gérer les modificateurs** : Shift, Ctrl, Alt
3. **Éviter les conflits** avec les raccourcis système Windows
4. **Fournir un guide visuel** (F1) avec tous les raccourcis
5. **Permettre la personnalisation** via un fichier de configuration
