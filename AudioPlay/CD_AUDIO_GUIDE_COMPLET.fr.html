AudioPlay peut maintenant lire et extraire des CD audio directement depuis vos lecteurs CD/DVD avec gestion complète des métadonnées, pochettes d'album multi-sources, et soumission à GnuDB.

🎵 Lecture de CD Audio

Accès au lecteur CD
Pour lire un CD audio :
  1. Insérez un CD audio dans votre lecteur CD/DVD
  2. Cliquez sur le bouton "Ajout" (Button_Ajout) dans la barre d'outils
  3. Dans le menu contextuel qui apparaît, choisissez "Ajout d'un CD Audio"
  4. AudioPlay détecte automatiquement les lecteurs contenant un CD audio
  5. Sélectionnez le lecteur dans la liste déroulante
  6. Les pistes du CD s'affichent automatiquement
Détection automatique : AudioPlay surveille en temps réel les lecteurs CD. Si vous éjectez ou insérez un CD, l'interface se met à jour automatiquement.

🎛️ FormSelecteurPistesCD - Sélection des pistes

Interface de sélection des pistes
Lors de l'ouverture d'un CD, le FormSelecteurPistesCD s'affiche avec :

📋 Liste des pistes disponibles :

  • ✅ Cases à cocher : Sélectionnez les pistes à extraire
  • 🎵 Numéro de piste : Numéro de la piste sur le CD
  • 📝 Titre : Nom de la chanson (si métadonnées disponibles)
  • ⏱️ Durée : Durée de la piste (mm:ss)

🎯 Boutons de sélection rapide :

  • Tout sélectionner : Coche toutes les pistes du CD
  • Tout désélectionner : Décoche toutes les pistes
  • Inverser la sélection : Inverse les cases cochées/décochées

🚀 Lancer l'extraction :

  • Extraction : Ouvre FormCompresser avec les pistes sélectionnées
  • Annuler : Ferme la fenêtre sans extraire
Note importante : Vous devez sélectionner au moins une piste pour pouvoir lancer l'extraction.

🖼️ Pochette d'album - Système multi-sources

Recherche intelligente de pochettes
AudioPlay recherche automatiquement les pochettes sur 4 sources différentes :

🌐 Sources de pochettes

Source Description Qualité
MusicBrainz Base de données musicale communautaire (Cover Art Archive) ⭐⭐⭐⭐⭐
Last.fm Service de streaming et base de données ⭐⭐⭐⭐
Discogs Base de données discographique mondiale ⭐⭐⭐⭐

🎨 Navigation entre les pochettes

  • ⬅️ Bouton Précédent : Affiche la pochette précédente dans l'historique
  • ➡️ Bouton Suivant : Recherche et affiche la prochaine pochette disponible
  • 🗑️ Bouton Effacer : Supprime la pochette actuelle et passe à la suivante

ℹ️ Informations de la pochette

  • Site : Indique la source de la pochette actuellement affichée
    (MusicBrainz, Last.fm, Discogs, ou Fanart.tv)
  • Dimensions : Taille de l'image en pixels (ex: 500 x 500)
  • Taille : Poids du fichier image en Ko ou Mo
Cache temporaire : Toutes les pochettes trouvées sont mises en cache temporairement. Vous pouvez naviguer entre elles avec les boutons Précédent/Suivant jusqu'à ce que vous trouviez celle qui vous convient.
Conservation de la pochette : La pochette affichée au moment où vous cliquez sur "Extraire" sera celle utilisée pour tous les fichiers extraits. Les autres pochettes du cache seront alors supprimées automatiquement.

📤 Soumission à GnuDB

Contribuer à la base de données GnuDB

🌍 Qu'est-ce que GnuDB ?

GnuDB est une base de données CD gratuite et communautaire. Si votre CD n'a pas été trouvé automatiquement, vous pouvez soumettre ses métadonnées pour aider les autres utilisateurs !

📤 Processus de soumission

  1. Remplir les métadonnées : Assurez-vous que tous les champs sont corrects (Artiste, Album, Année, Genre, Titres des pistes)
  2. Cliquer sur "Soumettre à GnuDB"
  3. Entrer votre adresse e-mail : OBLIGATOIRE pour que GnuDB puisse vous notifier
  4. Choisir la catégorie : AudioPlay propose automatiquement une catégorie basée sur le genre
  5. Mode de soumission :
    • ✅ Mode TEST (recommandé) : Le serveur vérifie mais n'enregistre pas
    • 🚀 Mode SUBMIT : Soumission réelle ajoutée à GnuDB
  6. Validation : AudioPlay calcule le DiscID CDDB et envoie les métadonnées
  7. Confirmation : Message de confirmation + e-mail de GnuDB
Format CDDB conforme : AudioPlay génère automatiquement un fichier CDDB au format standard avec toutes les métadonnées et le DiscID correct.
Conditions de soumission :
  • Tous les champs métadonnées doivent être remplis
  • Une adresse e-mail valide est obligatoire
  • Le DiscID CDDB doit pouvoir être calculé

⚙️ Processus d'extraction

  1. Sélectionner les pistes à extraire
  2. Choisir le format (MP3, FLAC, WAV, WMA)
  3. Choisir la qualité
  4. Définir le dossier de sauvegarde
  5. Ajuster les métadonnées
  6. Choisir la pochette (navigation ⬅️ ➡️)
  7. Éditer les pistes si nécessaire
  8. Options avancées :
    • ☑️ Verrouiller le CD
    • ☑️ Éjecter le CD après extraction
    • 🔊 Normalisation Son : Ajustez le volume d'extraction (1-100%, défaut 95%)
      • 95% : Valeur recommandée pour éviter la saturation
      • 100% : Volume maximum (risque de distorsion)
      • Moins de 95% : Réduction du volume si les pistes sont trop fortes
      • 💾 La valeur est sauvegardée automatiquement entre les sessions
  9. Cliquer sur "Extraire"
Organisation automatique :
Dossier\(Année) Artiste - Album\NN - Artiste - Titre.ext

Exemple :
Musique\(2005) Paul McCartney - Never Stop Doing What You Love\01 - Paul McCartney - Another Day.mp3

📊 Suivi de progression

  • Piste en cours : Affiche "Artiste - Titre"
  • Progression par piste : Barre 0-100%
  • Progression globale : Toutes les pistes

🎮 Contrôles pendant l'extraction

  • Annuler : Arrête l'extraction (pistes déjà extraites conservées)
  • Minimiser : Continue en arrière-plan
Extraction en arrière-plan : Vous pouvez même écouter de la musique dans AudioPlay pendant l'extraction !

❓ Questions fréquentes

💿 Mon CD n'est pas détecté

  • Vérifiez que c'est bien un CD audio
  • Cliquez de nouveau sur Button_Ajout → "Ajout d'un CD Audio"
  • Redémarrez AudioPlay si nécessaire

📝 Les métadonnées ne se chargent pas

  • Vérifiez votre connexion Internet
  • CD rare = saisissez manuellement
  • Soumettez ensuite à GnuDB pour aider les autres !

🖼️ La pochette ne s'affiche pas

  • Cliquez sur "Suivant ➡️" pour d'autres sources
  • Vous pouvez extraire sans pochette

⚡ L'extraction est lente

  • Normal : extraction = temps réel du CD
  • Une piste de 4 min = 4 min d'extraction
  • WAV = plus rapide (pas de compression)

📤 Soumission GnuDB échoue

  • Vérifiez que tous les champs sont remplis
  • E-mail valide obligatoire
  • Essayez d'abord en mode TEST
🎉 Astuce pro : Remplissez toutes les métadonnées avant extraction, choisissez une pochette haute qualité, et soumettez à GnuDB pour aider la communauté !
