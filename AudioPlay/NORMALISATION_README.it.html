🎵 Normalizzazione del Volume - Opzione 1

📋 Funzionalità

Questa funzione consente di normalizzare automaticamente il volume di tutti i file audio in modo che abbiano un livello di volume percepito simile durante la riproduzione.

⚙️ Come Funziona

1. Analisi Automatica

Quando un file audio viene riprodotto per la prima volta, il sistema analizza rapidamente il suo volume (primi 30 secondi)

L'analisi calcola:

  • Volume RMS (Root Mean Square): Il volume medio percepito
  • Volume di Picco: Il volume massimo
  • Guadagno Suggerito: Il moltiplicatore da applicare per la normalizzazione

2. Regolazione Automatica

Il sistema regola automaticamente il volume in base al guadagno calcolato

La regolazione viene applicata in tempo reale senza modificare il file originale

3. Archiviazione dei Dati

I risultati dell'analisi vengono memorizzati in un database in modo da non doverli ricalcolare ad ogni riproduzione

Posizione del database: %AppData%\AudioPlay\audioplay.db

🎯 Volume Obiettivo

Obiettivo predefinito: -23 LUFS (Loudness Units Full Scale)

Questo è lo standard utilizzato dalle piattaforme di streaming come Spotify e YouTube

✅ Vantaggi

  • ✅ Volume coerente tra tutte le tracce
  • ✅ Nessuna regolazione manuale del volume necessaria
  • ✅ File originali invariati
  • ✅ Veloce e automatico
  • ✅ Funziona con tutti i formati audio

⚙️ Come Attivare/Disattivare

  1. Aprire le Impostazioni
  2. Trovare la sezione "Normalizzazione del Volume"
  3. Selezionare o deselezionare la casella di normalizzazione
  4. L'impostazione ha effetto immediato

🔍 Dettagli Tecnici

Metodo di Analisi

  • Campione analizzato: Primi 30 secondi del file
  • Calcolo RMS: Radice quadrata della media dei campioni al quadrato
  • Rilevamento dei picchi: Valore assoluto massimo di tutti i campioni
  • Calcolo del guadagno: Rapporto tra l'obiettivo e l'RMS misurato

Limiti

  • Guadagno massimo: +20 dB (per evitare clipping)
  • Guadagno minimo: -20 dB (per evitare audio troppo basso)
  • Protezione dei picchi: Riduce automaticamente il guadagno se causerebbe clipping

❓ Domande Frequenti

Perché a volte il primo secondo di riproduzione ha un volume errato?

L'analisi viene eseguita durante la riproduzione. Il volume corretto viene applicato dopo il primo secondo.

Posso modificare il volume obiettivo?

La versione attuale utilizza un obiettivo fisso di -23 LUFS, che è lo standard del settore.

I miei file originali vengono modificati?

No! La regolazione del volume viene applicata solo durante la riproduzione. I file originali rimangono invariati.

Cosa succede se disattivo la normalizzazione?

I file verranno riprodotti al loro volume originale. I dati di analisi vengono conservati e verranno riutilizzati se si riattiva la normalizzazione.

🔧 Risoluzione dei Problemi

La normalizzazione non sembra funzionare

  1. Verificare che la normalizzazione sia attivata nelle impostazioni
  2. Riavviare AudioPlay
  3. Provare a riprodurre un nuovo file

Alcuni file sono ancora troppo forti o troppo bassi

Questo può accadere con file che hanno:

  • Un silenzio molto lungo all'inizio
  • Audio molto dinamico (ad esempio musica classica)
  • Clipping o distorsione nel file originale

🔊 Controllo Volume Estrazione CD

Funzione: Regola il volume di estrazione durante il ripping di CD audio

Questo è diverso dalla normalizzazione della riproduzione - imposta permanentemente il livello di volume dei file estratti.

⚙️ Come Usare

  1. Apri il Modulo di Estrazione CD (FormCompresser)
  2. Trova il controllo "Normalizzazione Audio"
  3. Regola il valore (1-100%, predefinito: 95%)
  4. L'impostazione viene salvata automaticamente per le sessioni future

📊 Valori Consigliati

  • 🎵 95% (Predefinito): Consigliato per evitare saturazione/clipping
  • ⚠️ 100%: Volume massimo (rischio di distorsione su tracce forti)
  • 🔽 Meno del 95%: Ridurre il volume se le tracce sono troppo forti
  • 💾 Persistente: Il valore scelto viene salvato tra le sessioni
⚠️ Importante: Questa impostazione influisce sui file estratti permanentemente. A differenza della normalizzazione di riproduzione, non è possibile modificarla dopo l'estrazione.
💡 Suggerimento: Per risultati ottimali, lasciare che AudioPlay analizzi tutti i file alla prima riproduzione. Le riproduzioni successive utilizzeranno automaticamente il volume corretto!
