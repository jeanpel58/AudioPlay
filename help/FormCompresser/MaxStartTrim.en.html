⏮️Max start trim (seconds)

This parameter limits how far the analyzer is allowed to move the detected start of the next track earlier when compensating for overlap or misaligned TOC boundaries.

Why it exists

On some CDs tracks overlap or the next track's start in the TOC is slightly late. Limiting the maximum start-trim prevents the analyzer from moving the start too far and accidentally cutting important audio.

Effect of changing it

  • Smaller value: conservative, safer against cutting wanted audio but may keep overlap.
  • Larger value: more aggressive at removing overlaps, but risky if set too large.
Recommendation: default: 8.0s. Increase for strongly overlapping masters, decrease to be conservative. Avoid extreme values.
