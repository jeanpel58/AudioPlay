🎵 Normalización de Volumen - Opción 1

📋 Característica

Esta función le permite normalizar automáticamente el volumen de todos los archivos de audio para que tengan un nivel de volumen percibido similar durante la reproducción.

⚙️ Cómo Funciona

1. Análisis Automático

Cuando se reproduce un archivo de audio por primera vez, el sistema analiza rápidamente su volumen (primeros 30 segundos)

El análisis calcula:

  • Volumen RMS (Root Mean Square): El volumen promedio percibido
  • Volumen Pico: El volumen máximo
  • Ganancia Sugerida: El multiplicador a aplicar para la normalización

2. Ajuste Automático

El sistema ajusta automáticamente el volumen según la ganancia calculada

El ajuste se aplica en tiempo real sin modificar el archivo original

3. Almacenamiento de Datos

Los resultados del análisis se almacenan en una base de datos para no tener que recalcularlos en cada reproducción

Ubicación de la base de datos: %AppData%\AudioPlay\audioplay.db

🎯 Volumen Objetivo

Objetivo predeterminado: -23 LUFS (Loudness Units Full Scale)

Este es el estándar utilizado por plataformas de streaming como Spotify y YouTube

✅ Beneficios

  • ✅ Volumen consistente entre todas las pistas
  • ✅ Sin ajuste manual de volumen necesario
  • ✅ Archivos originales sin cambios
  • ✅ Rápido y automático
  • ✅ Funciona con todos los formatos de audio

⚙️ Cómo Activar/Desactivar

  1. Abrir Configuración
  2. Buscar la sección "Normalización de Volumen"
  3. Marcar o desmarcar la casilla de normalización
  4. La configuración surte efecto inmediatamente

🔍 Detalles Técnicos

Método de Análisis

  • Muestra analizada: Primeros 30 segundos del archivo
  • Cálculo RMS: Raíz cuadrada de la media de muestras al cuadrado
  • Detección de picos: Valor absoluto máximo de todas las muestras
  • Cálculo de ganancia: Relación entre el objetivo y el RMS medido

Límites

  • Ganancia máxima: +20 dB (para evitar recortes)
  • Ganancia mínima: -20 dB (para evitar audio demasiado bajo)
  • Protección de picos: Reduce automáticamente la ganancia si causaría recortes

❓ Preguntas Frecuentes

¿Por qué a veces el primer segundo de reproducción tiene volumen incorrecto?

El análisis se realiza durante la reproducción. El volumen correcto se aplica después del primer segundo.

¿Puedo cambiar el volumen objetivo?

La versión actual utiliza un objetivo fijo de -23 LUFS, que es el estándar de la industria.

¿Se modifican mis archivos originales?

¡No! El ajuste de volumen se aplica solo durante la reproducción. Sus archivos originales permanecen sin cambios.

¿Qué sucede si desactivo la normalización?

Los archivos se reproducirán a su volumen original. Los datos de análisis se conservan y se reutilizarán si vuelve a activar la normalización.

🔧 Solución de Problemas

La normalización no parece funcionar

  1. Verificar que la normalización esté activada en la configuración
  2. Reiniciar AudioPlay
  3. Intentar reproducir un archivo nuevo

Algunos archivos siguen siendo demasiado fuertes o demasiado bajos

Esto puede suceder con archivos que tienen:

  • Un silencio muy largo al principio
  • Audio muy dinámico (música clásica, por ejemplo)
  • Recortes o distorsión en el archivo original

🔊 Control de Volumen de Extracción de CD

Función: Ajuste el volumen de extracción al ripear CDs de audio

Esto es diferente de la normalización de reproducción - establece permanentemente el nivel de volumen de los archivos extraídos.

⚙️ Cómo Usar

  1. Abra el Formulario de Extracción de CD (FormCompresser)
  2. Encuentre el control "Normalización de Sonido"
  3. Ajuste el valor (1-100%, predeterminado: 95%)
  4. La configuración se guarda automáticamente para sesiones futuras

📊 Valores Recomendados

  • 🎵 95% (Predeterminado): Recomendado para evitar saturación/recorte
  • ⚠️ 100%: Volumen máximo (riesgo de distorsión en pistas ruidosas)
  • 🔽 Menos del 95%: Reduzca el volumen si las pistas son demasiado ruidosas
  • 💾 Persistente: Su valor elegido se guarda entre sesiones
⚠️ Importante: Esta configuración afecta los archivos extraídos permanentemente. A diferencia de la normalización de reproducción, no puede cambiarla después de la extracción.
💡 Consejo: Para obtener resultados óptimos, deje que AudioPlay analice todos sus archivos en la primera reproducción. ¡Las reproducciones posteriores usarán automáticamente el volumen correcto!
