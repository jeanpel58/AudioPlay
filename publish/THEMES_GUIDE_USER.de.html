🎨 AudioPlay - Farbthemensystem

🎉 Neue Funktionen!
AudioPlay verfügt jetzt über ein vollständiges Farbthemen-Verwaltungssystem. Sie können das Erscheinungsbild Ihres Audioplayers vollständig anpassen!

🚀 Schnellstart

Wie ändert man das Thema?

  1. Öffnen Sie Einstellungen (Menü oder Einstellungsschaltfläche)
  2. Gehen Sie zum Abschnitt "Schnittstellenfarben"
  3. Verwenden Sie das Dropdown-Menü "Thema auswählen"
  4. Wählen Sie aus:
    • 🎨 Standard - Das ursprüngliche AudioPlay-Thema (hellblau)
    • 🌙 Dunkel - Nachtmodus mit dunkelgrauem Hintergrund
    • ☀️ Sonne - Hell und energiegeladen gelb
    • 🌊 Ozean - Beruhigendes Himmelblau
    • 🍂 Herbst - Warm und einladend golden

Das Thema wird sofort auf die gesamte Benutzeroberfläche angewendet!

✨ Eigenes Thema erstellen

Schritt 1: Farben anpassen

  1. In Einstellungen > Schnittstellenfarben
  2. Klicken Sie auf "Ein Farbthema erstellen..."
  3. Ein Fenster öffnet sich mit allen anpassbaren Elementen:
    • Formularhintergründe
    • Steuerelementhintergründe
    • Schaltflächenfarben
    • Wiedergabelistenfarben
    • Und vieles mehr!

Schritt 2: Farben auswählen

  1. Wählen Sie ein Element aus der Liste
  2. Klicken Sie auf "Farbe wählen..."
  3. Verwenden Sie den Farbwähler
  4. Klicken Sie auf "Anwenden", um das Ergebnis live zu sehen
  5. Fahren Sie fort, bis Sie das gewünschte Erscheinungsbild erhalten
  6. Klicken Sie auf "OK", wenn Sie zufrieden sind

Schritt 3: Thema speichern

  1. Klicken Sie auf "Speichern als..."
  2. Geben Sie einen Namen für Ihr Thema ein (z.B. "Mein lila Thema")
  3. Bestätigen
  4. Ihr Thema ist jetzt in der Liste!

🗑️ Thema löschen

  1. Wählen Sie das zu löschende Thema aus der Dropdown-Liste
  2. Klicken Sie auf "Löschen"
  3. Bestätigen Sie das Löschen
  4. Das "Standard"-Thema wird automatisch wieder aktiviert
⚠️ Hinweis: Das "Standard"-Thema kann nicht gelöscht werden.

🔄 Farben zurücksetzen

Klicken Sie jederzeit auf "Zurücksetzen", um zu den Standardfarben von AudioPlay zurückzukehren.

Dies löscht Ihre benutzerdefinierten Themen nicht; Sie können sie später wiederverwenden.

💾 Wo werden Themen gespeichert?

Themen werden gespeichert in:

%AppData%\AudioPlay\Themes\

Jedes Thema ist eine einfache Textdatei mit der Erweiterung .theme

🔧 Tipps

  • Vor dem Speichern testen: Änderungen werden live angewendet, Sie sehen die Ergebnisse sofort
  • Änderungen abbrechen: Klicken Sie auf "Abbrechen", um zum ursprünglichen Thema zurückzukehren
  • Themen teilen: Kopieren Sie .theme-Dateien, um sie mit anderen Benutzern zu teilen
  • Variationen erstellen: Wählen Sie ein vorhandenes Thema als Basis, ändern Sie es und speichern Sie es unter einem neuen Namen

❓ Häufige Probleme

Das Thema wird nach dem Neustart nicht angewendet

Lösung: Stellen Sie sicher, dass Sie nach der Auswahl des Themas auf "Speichern" klicken. Die Schaltfläche "Abbrechen" bricht alle Änderungen ab.

Schaltflächen mit Bildern haben eine Hintergrundfarbe

Lösung: Dieses Problem wurde behoben. Wenn Sie es noch immer haben, schließen und starten Sie AudioPlay neu.

Mein benutzerdefiniertes Thema ist verschwunden

Lösung: Überprüfen Sie in %AppData%\AudioPlay\Themes\, ob Ihre .theme-Datei noch existiert. Wenn ja, sollte das Thema beim nächsten Start in der Liste erscheinen.

💡 Tipp: Zögern Sie nicht zu experimentieren! Sie können jederzeit zum Standardthema zurückkehren, indem Sie auf "Zurücksetzen" klicken oder "Standard" aus der Liste auswählen.
