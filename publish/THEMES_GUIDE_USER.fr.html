🎨 AudioPlay - Système de thèmes de couleurs

🎉 Nouvelles fonctionnalités !
AudioPlay dispose maintenant d'un système complet de gestion des thèmes de couleurs. Vous pouvez personnaliser entièrement l'apparence de votre lecteur audio !

🚀 Démarrage rapide

Comment changer de thème ?

  1. Ouvrez Paramètres (menu ou bouton paramètres)
  2. Allez dans la section "Couleurs de l'interface"
  3. Utilisez le menu déroulant "Sélectionner un thème"
  4. Choisissez parmi :
    • 🎨 Par défaut - Le thème original AudioPlay (bleu clair)
    • 🌙 Sombre - Mode nuit avec fond gris foncé
    • ☀️ Soleil - Jaune vif et énergique
    • 🌊 Océan - Bleu ciel apaisant
    • 🍂 Automne - Doré chaud et accueillant

Le thème s'applique instantanément à toute l'interface !

✨ Créer votre propre thème

Étape 1 : Ouvrir l'éditeur de thème

  1. Dans Paramètres > Couleurs de l'interface
  2. Cliquez sur "Créer un thème de couleurs..."
  3. 💡 Astuce : Vous pouvez partir de n'importe quel thème ! Sélectionnez d'abord un thème qui vous plaît, puis cliquez sur "Créer un thème de couleurs..." pour le personnaliser

Étape 2 : Personnaliser les couleurs

  1. Une fenêtre s'ouvre avec tous les éléments modifiables :
    • Fond des formulaires
    • Fond des contrôles
    • Couleurs des boutons
    • Couleurs de la liste de lecture
    • Et bien plus !
  2. Sélectionnez un élément dans la liste
  3. Cliquez sur "Choisir couleur..."
  4. Utilisez le sélecteur de couleur pour choisir votre couleur

Étape 3 : Prévisualiser vos changements

  1. Cliquez sur "Appliquer" pour voir vos modifications en temps réel
  2. ✨ L'interface se met à jour instantanément !
  3. Continuez à ajuster les couleurs jusqu'à obtenir le résultat souhaité
  4. ⚠️ Important : Ces modifications sont temporaires, elles ne seront pas conservées tant que vous n'aurez pas sauvegardé le thème

Étape 4 : Sauvegarder votre thème

  1. Quand vous êtes satisfait du résultat, cliquez sur "OK"
  2. Une boîte de dialogue vous demande le nom de votre thème
  3. Entrez un nom unique (ex: "Mon thème violet", "Thème professionnel")
  4. 🔒 Attention : Vous ne pouvez pas utiliser les noms réservés :
    • Par défaut
    • Automne
    • Océan
    • Soleil
    • Sombre
  5. Cliquez sur OK pour confirmer, ou laissez vide pour annuler
  6. ✅ Votre thème est sauvegardé et apparaît maintenant dans la liste !
  7. 📋 L'apparence revient à l'état d'origine (avant vos modifications)

Étape 5 : Activer votre nouveau thème

  1. Dans la liste déroulante "Sélectionner un thème", choisissez votre nouveau thème
  2. L'aperçu s'affiche instantanément
  3. Cliquez sur "Sauvegarder" pour appliquer définitivement le thème

📋 Dupliquer un thème existant

  1. Sélectionnez le thème que vous souhaitez dupliquer dans la liste
  2. Cliquez sur "Enregistrer le thème sous"
  3. Entrez un nouveau nom pour la copie
  4. ✅ Une copie identique est créée sous le nouveau nom !
  5. Vous pouvez ensuite la modifier avec "Créer un thème de couleurs..."

🗑️ Supprimer un thème

  1. Sélectionnez le thème à supprimer dans la liste déroulante
  2. Cliquez sur "Supprimer"
  3. Confirmez la suppression
  4. Le thème "Par défaut" sera automatiquement réactivé
⚠️ Note : Les thèmes préinstallés suivants ne peuvent pas être supprimés :
  • 🎨 Par défaut
  • 🍂 Automne
  • 🌊 Océan
  • ☀️ Soleil
  • 🌙 Sombre
Ces thèmes sont protégés pour garantir que vous avez toujours des options de base disponibles.

🔄 Réinitialiser les couleurs

À tout moment, cliquez sur "Couleurs par défaut" pour revenir aux couleurs par défaut d'AudioPlay.

⚠️ Ce bouton n'est disponible que si vous n'avez pas sélectionné un thème préinstallé protégé.

💡 Cette action ne supprime pas vos thèmes personnalisés, vous pourrez toujours les réutiliser plus tard.

🎨 Éléments personnalisables

Vous pouvez modifier les couleurs de :

Élément Description
🖼️ Fond des formulaires Couleur d'arrière-plan des fenêtres
🎛️ Fond des contrôles Zones de contrôle et panneaux
🔤 Texte des contrôles Couleur du texte général
🔘 Fond des boutons Arrière-plan des boutons
📝 Texte des boutons Texte sur les boutons
📋 Fond de la liste Liste des chansons
📄 Texte de la liste Texte dans la liste
📊 Entête de liste Barre d'en-tête des colonnes
✅ Sélection Surbrillance des éléments sélectionnés
📝 Zones de texte Champs de saisie
📦 Groupes Titres des sections
🎚️ Curseurs Barres de volume et position

💾 Où sont stockés les thèmes ?

Les thèmes sont enregistrés dans :

%AppData%\AudioPlay\Themes\

Chaque thème est un simple fichier texte avec l'extension .theme

🔧 Astuces

  • Partir d'une base : Sélectionnez un thème existant qui vous plaît avant de cliquer sur "Créer un thème de couleurs..." - vos modifications partiront de ce thème !
  • Prévisualiser en direct : Cliquez sur "Appliquer" dans l'éditeur pour voir vos modifications instantanément
  • Annuler facilement : Si vous n'aimez pas le résultat, cliquez sur "Annuler" dans l'éditeur ou laissez le nom vide lors de la sauvegarde
  • Dupliquer pour modifier : Utilisez "Enregistrer le thème sous" pour créer une copie d'un thème que vous pourrez ensuite personnaliser
  • Partager vos créations : Copiez les fichiers .theme pour les partager avec d'autres utilisateurs
  • Protéger vos créations : Les thèmes que vous créez peuvent être modifiés et re-sauvegardés, contrairement aux thèmes préinstallés qui sont protégés

❓ Problèmes courants

Le thème ne s'applique pas après le redémarrage

Solution : Assurez-vous de cliquer sur "Sauvegarder" après avoir sélectionné le thème. Le bouton "Annuler" annule toutes les modifications.

Les boutons avec images ont une couleur de fond

Solution : Ce problème a été corrigé. Si vous le rencontrez encore, fermez et redémarrez AudioPlay.

Mon thème personnalisé a disparu

Solution : Vérifiez dans %AppData%\AudioPlay\Themes\ si votre fichier .theme existe toujours. Si oui, le thème devrait apparaître dans la liste au prochain démarrage.

💡 Conseil : N'hésitez pas à expérimenter ! Vous pouvez toujours revenir au thème par défaut en cliquant sur "Réinitialiser" ou en sélectionnant "Par défaut" dans la liste.
