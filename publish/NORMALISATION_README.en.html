🎵 Volume Normalization - Option 1

📋 Feature

This feature allows you to automatically normalize the volume of all audio files so they have a similar perceived volume level during playback.

⚙️ How It Works

1. Automatic Analysis

When an audio file is played for the first time, the system quickly analyzes its volume (first 30 seconds)

The analysis calculates:

  • RMS Volume (Root Mean Square): The average perceived volume
  • Peak Volume: The maximum volume
  • Suggested Gain: The multiplier to apply for normalization

2. Automatic Adjustment

The system automatically adjusts the volume based on the calculated gain

The adjustment is applied in real time without modifying the original file

3. Data Storage

Analysis results are stored in a database so they don't need to be recalculated on each playback

Database location: %AppData%\AudioPlay\audioplay.db

🎯 Target Volume

Default target: -23 LUFS (Loudness Units Full Scale)

This is the standard used by streaming platforms like Spotify and YouTube

✅ Benefits

  • ✅ Consistent volume between all tracks
  • ✅ No manual volume adjustment needed
  • ✅ Original files unchanged
  • ✅ Fast and automatic
  • ✅ Works with all audio formats

⚙️ How to Enable/Disable

  1. Open Settings
  2. Find the "Volume Normalization" section
  3. Check or uncheck the normalization checkbox
  4. The setting takes effect immediately

🔍 Technical Details

Analysis Method

  • Sample analyzed: First 30 seconds of the file
  • RMS calculation: Square root of the mean of squared samples
  • Peak detection: Maximum absolute value of all samples
  • Gain calculation: Ratio between target and measured RMS

Limits

  • Maximum gain: +20 dB (to avoid clipping)
  • Minimum gain: -20 dB (to avoid audio too quiet)
  • Peak protection: Automatically reduces gain if it would cause clipping

❓ FAQ

Why does the first second of playback sometimes have incorrect volume?

The analysis is done during playback. The correct volume is applied after the first second.

Can I change the target volume?

The current version uses a fixed target of -23 LUFS, which is the industry standard.

Are my original files modified?

No! Volume adjustment is applied only during playback. Your original files remain unchanged.

What happens if I disable normalization?

Files will play at their original volume. Analysis data is preserved and will be reused if you re-enable normalization.

🔧 Troubleshooting

Normalization doesn't seem to work

  1. Check that normalization is enabled in settings
  2. Restart AudioPlay
  3. Try playing a new file

Some files are still too loud or too quiet

This can happen with files that have:

  • A very long silence at the beginning
  • Very dynamic audio (classical music, for example)
  • Clipping or distortion in the original file

🔊 CD Extraction Volume Control

Feature: Adjust the extraction volume when ripping audio CDs

This is different from playback normalization - it permanently sets the volume level of extracted files.

⚙️ How to Use

  1. Open the CD Extraction Form (FormCompresser)
  2. Find the "Sound Normalization" control
  3. Adjust the value (1-100%, default: 95%)
  4. The setting is automatically saved for future sessions

📊 Recommended Values

  • 🎵 95% (Default): Recommended to avoid saturation/clipping
  • ⚠️ 100%: Maximum volume (risk of distortion on loud tracks)
  • 🔽 Less than 95%: Reduce volume if tracks are too loud
  • 💾 Persistent: Your chosen value is saved between sessions
⚠️ Important: This setting affects the extracted files permanently. Unlike playback normalization, you cannot change it after extraction.
💡 Tip: For optimal results, let AudioPlay analyze all your files on first playback. Subsequent playbacks will automatically use the correct volume!
