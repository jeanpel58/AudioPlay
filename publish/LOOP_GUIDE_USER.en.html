🔁Loop Function

The Loop button allows you to repeat a specific section of the current song, ideal for learning a musical passage or practicing an instrument.

📝How to Use the Loop Function

1️⃣ Start Playback
Start playing a song with the Play button or by double-clicking a song in the list.
2️⃣ Mark the Loop Start
During playback, press the I key (for "In" or "Start") at the point where you want the loop to begin.
3️⃣ Mark the Loop End
Continue listening and press the O key (for "Out" or "End") at the point where you want the loop to end.
4️⃣ View the Markers
Two small markers I and O appear above the progress bar to indicate the loop zone.
5️⃣ Activate the Loop
Click the Loop button. The button turns light green to indicate the loop is active.
6️⃣ The Section Plays in a Loop
The part between I and O repeats automatically without stopping.

🔄Disable the Loop

To stop looping, click the Loop button again. The button returns to its normal color and playback continues normally.

🗑️Marker Reset

The I and O markers disappear automatically when:

  • You load a new song (double-click or Play button)
  • You completely stop playback with the Stop button or Ctrl+Space
💡 Note: Loops are specific to each song. Each time you play a new song, you must define new markers.

⏸️Behavior with Pause and Mute

  • Pause/Resume: The loop pauses with playback and resumes at the same point when you click Pause/Resume or press Space.
  • Mute: The loop continues running silently. Sound returns as soon as you disable mute mode.

🎨Marker Color

The I and O markers display in red by default. If you have created a theme with a red or very dark background, the markers automatically display in yellow to remain clearly visible.

🚫Restrictions

⚠️ BPM Calculation Blocked: The BPM Calculation button does not work while a loop is active. Disable the loop first if you want to calculate the song's tempo.

💡Tips

The Loop function is particularly useful for:

  • Learning song lyrics
  • Practicing a guitar or piano solo
  • Working on difficult passages
  • Analyzing a musical section in detail
