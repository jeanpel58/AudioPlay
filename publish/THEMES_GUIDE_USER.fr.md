# 🎨 AudioPlay - Système de thèmes de couleurs

## 🎉 Nouvelles fonctionnalités !

AudioPlay dispose maintenant d'un système complet de gestion des thèmes de couleurs. Vous pouvez personnaliser entièrement l'apparence de votre lecteur audio !

---

## 🚀 Démarrage rapide

### Comment changer de thème ?

1. Ouvrez **Paramètres** (menu ou bouton paramètres)
2. Allez dans la section **"Couleurs de l'interface"**
3. Utilisez le menu déroulant **"Sélectionner un thème"**
4. Choisissez parmi :
   - 🎨 **Par défaut** - Le thème original AudioPlay (bleu clair)
   - 🌙 **Sombre** - Mode nuit avec fond gris foncé
   - ☀️ **Soleil** - Jaune vif et énergique
   - 🌊 **Océan** - Bleu ciel apaisant
   - 🍂 **Automne** - Doré chaud et accueillant

Le thème s'applique **instantanément** à toute l'interface !

---

## ✨ Créer votre propre thème

### Étape 1 : Personnaliser les couleurs

1. Dans **Paramètres** > **Couleurs de l'interface**
2. Cliquez sur **"Personnaliser..."**
3. Une fenêtre s'ouvre avec tous les éléments modifiables :
   - Fond des formulaires
   - Fond des contrôles
   - Couleurs des boutons
   - Couleurs de la liste de lecture
   - Et bien plus !

### Étape 2 : Choisir vos couleurs

1. Sélectionnez un élément dans la liste
2. Cliquez sur **"Choisir couleur..."**
3. Utilisez le sélecteur de couleur
4. Cliquez sur **"Appliquer"** pour voir le résultat en direct
5. Continuez jusqu'à obtenir l'apparence souhaitée
6. Cliquez sur **"OK"** quand vous êtes satisfait

### Étape 3 : Enregistrer votre thème

1. Cliquez sur **"Enr. sous..."** (Enregistrer sous)
2. Entrez un nom pour votre thème (ex: "Mon thème violet")
3. Validez
4. Votre thème est maintenant dans la liste !

---

## 🗑️ Supprimer un thème

1. Sélectionnez le thème à supprimer dans la liste déroulante
2. Cliquez sur **"Supprimer"**
3. Confirmez la suppression
4. Le thème **"Par défaut"** sera automatiquement réactivé

⚠️ **Note** : Le thème "Par défaut" ne peut pas être supprimé.

---

## 🔄 Réinitialiser les couleurs

À tout moment, cliquez sur **"Réinitialiser"** pour revenir aux couleurs par défaut d'AudioPlay.

Cela ne supprime pas vos thèmes personnalisés, vous pourrez toujours les réutiliser plus tard.

---

## 🎨 Éléments personnalisables

Vous pouvez modifier les couleurs de :

| Élément | Description |
|---------|-------------|
| 🖼️ **Fond des formulaires** | Couleur d'arrière-plan des fenêtres |
| 🎛️ **Fond des contrôles** | Zones de contrôle et panneaux |
| 🔤 **Texte des contrôles** | Couleur du texte général |
| 🔘 **Fond des boutons** | Arrière-plan des boutons |
| 📝 **Texte des boutons** | Texte sur les boutons |
| 📋 **Fond de la liste** | Liste des chansons |
| 📄 **Texte de la liste** | Texte dans la liste |
| 📊 **Entête de liste** | Barre d'en-tête des colonnes |
| ✅ **Sélection** | Surbrillance des éléments sélectionnés |
| 📝 **Zones de texte** | Champs de saisie |
| 📦 **Groupes** | Titres des sections |
| 🎚️ **Curseurs** | Barres de volume et position |

## 💾 Partager vos thèmes

### Exporter un thème

Vos thèmes sont sauvegardés dans :
```
%AppData%\AudioPlay\Themes\
```

Pour partager un thème avec un ami :
1. Ouvrez ce dossier (copiez-collez le chemin ci-dessus dans l'Explorateur)
2. Copiez le fichier `.theme` de votre thème
3. Envoyez-le par email, USB, etc.

### Importer un thème reçu

Si quelqu'un vous envoie un fichier `.theme` :
1. Copiez le fichier dans `%AppData%\AudioPlay\Themes\`
2. Redémarrez AudioPlay (ou fermez/rouvrez les Paramètres)
3. Le thème apparaît dans la liste !

## 💡 Conseils et astuces

### 🎨 Créer un thème harmonieux
- Utilisez des couleurs de la même famille
- Évitez les contrastes trop violents (sauf si c'est votre style !)
- Testez la lisibilité : le texte doit rester visible

### 👁️ Prévisualiser en temps réel
- Utilisez le bouton **"Appliquer"** dans l'éditeur
- Vous verrez les changements immédiatement
- N'hésitez pas à expérimenter !

### 💾 Sauvegarder souvent
- Créez des variantes de vos thèmes
- Donnez-leur des noms clairs (ex: "Bleu foncé v1", "Bleu foncé v2")
- Vous pourrez comparer et choisir votre préféré

### 🌈 S'inspirer des thèmes existants
- Essayez tous les thèmes préinstallés
- Notez ce que vous aimez dans chacun
- Combinez vos idées préférées dans un thème personnalisé

## 🔧 Problèmes courants

### ❓ Mon thème ne s'affiche pas dans la liste

**Solutions** :
- Vérifiez que le fichier est bien dans `%AppData%\AudioPlay\Themes\`
- Le fichier doit avoir l'extension `.theme` (pas `.theme.txt`)
- Redémarrez AudioPlay

### ❓ Les couleurs sont bizarres après modification

**Solutions** :
- Cliquez sur **"Réinitialiser"** pour revenir au thème par défaut
- Supprimez le thème problématique
- Recréez-le en faisant attention aux choix de couleurs

### ❓ Je ne peux pas supprimer un thème

**Raisons possibles** :
- Vous essayez de supprimer "Par défaut" (impossible par sécurité)
- Le thème est peut-être protégé en écriture (rare)

### ❓ Le texte est illisible sur certains fonds

**Solution** :
- Dans **"Personnaliser..."**, ajustez les couleurs de texte
- Règle générale : texte clair sur fond foncé, texte foncé sur fond clair
- Utilisez le bouton **"Appliquer"** pour vérifier
